### 1. ИССЛЕДОВАНИЕ ФУНКЦИОНАЛА УТИЛИТ

| Утилита | Возможности в контексте | Ограничения / Риски для "убитого" диска |
|---------|-------------------------|-----------------------------------------|
| **DMDE** | RAW-скан, HEX, восстановление разделов, извлечение файлов, работа с VHD/VHDX. | Нет горячего клонирования. Требует ручного вмешательства. |
| **DiskGenius** | Менеджер разделов, HEX, бэкап секторов, восстановление файлов, работа с VHD. | Агрессивные операции записи могут добить диск. |
| **Rescuezilla** | GUI для Clonezilla. Поддержка `ddrescue` (щадящее чтение bad-секторов). | Только поблочное клонирование. Не умеет извлекать отдельные файлы. |
| **R-Studio** | Глубокий анализ ФС, RAID, сетевое восстановление, создание образов. | Платная (в полной мере). Тяжеловесна. |
| **Hasleo Backup** | Горячее клонирование (VSS), миграция в VHDX, инкрементальные бэкапы. | **Критично:** Требует живой ОС. На умирающем диске VSS вызовет фриз и смерть диска. |
| **DISM++** | Управление WIM/ESD, извлечение драйверов, оптимизация ОС, правка реестра оффлайн. | Не работает с физическими дисками/образами IMG. Только WIM/VHDX/ESD. |
| **TestDisk** | Восстановление упавших таблиц разделов, загрузочных секторов. | Только CLI. Не восстанавливает удаленные файлы (только структуру). |
| **PhotoRec** | Карвинг (поиск файлов по сигнатурам). Игнорирует ФС. | Теряет имена файлов и структуру папок. Не подходит для восстановления ОС. |
| **Rufus** | Запись ISO/WIM на USB, создание загрузочных флешек. | Только запись. Не для извлечения. |
| **Bootice** | Редактор MBR/PBR/BCD, управление загрузчиками. | Только низкоуровневая правка загрузчика. Не для данных. |
| **FRST** | Аудит автозапуска, логов, реестра неактивной ОС. | Только анализ. Не извлекает и не восстанавливает. |
| **Acronis / Paragon** | Коммерческие миграторы, создание бэкапов. | Платные. На dead-дисках работают плохо без специализированной WinPE. |
| **FreeFileSync** | Синхронизация папок. | **Не использовать** на умирающих дисках (генерирует тысячи операций чтения). |
| **Recuva** | Базовое восстановление удаленных файлов. | Поверхностный скан. Бесполезна при повреждении ФС. |

### 2. СОРТИРОВКА И ТОП-12

#### 🟢 Универсальные (Покрывают весь цикл: Извлечение → Манипуляция → Деплой)
1. **DMDE** (Эталон для RAW/HEX и извлечения файлов).
2. **DiskGenius** (Управление разделами + восстановление + VHD).
3. **Rescuezilla** (Безопасное поблочное клонирование умирающих дисков).
4. **R-Studio** (Глубокая реконструкция ФС и извлечение).
5. **Hasleo Backup** (Только для клонирования *здоровых* систем в VHDX).
6. **DISM++** (Манипуляции с оффлайн-образами WIM/VHDX, драйверы).

#### 🟡 Эффективные (Лучшие в классе для узких подзадач)
1. **TestDisk** (Восстановление упавших таблиц разделов).
2. **PhotoRec** (Спасение файлов при уничтоженной ФС).
3. **Rufus** (Деплой ISO/WIM на флешки).
4. **Bootice** (Правка BCD/MBR для загрузки VHDX/WTG).
5. **FRST** (Аудит и очистка реестра/автозапуска перед клонированием).
6. **Acronis/Paragon** (Альтернатива Hasleo, если есть лицензия).

#### 🔴 Не для этих задач
* **FreeFileSync** (Убьет умирающий диск).
* **Recuva** (Слишком слаба для инженерных задач).



### 4. ИТОГОВЫЙ ГАЙД: АЛГОРИТМ РАБОТЫ С "УБИТЫМ" ДИСКОМ

#### ⚠️ ЗОЛОТОЕ ПРАВИЛО ИНЖЕНЕРА
**Никогда не монтируйте умирающий диск в Windows и не запускайте на нем Hasleo/Recuva/DiskGenius в режиме чтения ФС!** Каждая попытка Windows прочитать bad-сектор вызывает таймаут, нагрев и расширение поврежденной области.

#### ЭТАП 1: Стабилизация и Снятие образа (Rescuezilla)
*Цель: Создать безопасную копию на вашем Nexdrive P60 (Раздел 3).*
1. Загрузите ПК-пациент с **Rescuezilla** (ISO на SD400).
2. Подключите Nexdrive P60.
3. Выберите **Clone** → **Image** (Создать образ).
4. **Критично:** В настройках включите `ddrescue` (или аналог щадящего чтения). Это позволит пропустить bad-секторы и вернуться к ним позже.
5. Сохраните образ как `Patient_Disk.img` на P60.

#### ЭТАП 2: Анализ и Извлечение (DMDE / DiskGenius)
*Цель: Достать данные из `.img` без риска для оригинала.*
1. Откройте **DMDE** на рабочей станции (Win11).
2. Откройте файл `Patient_Disk.img` (Файл → Открыть образ).
3. **Восстановление структуры:** Найдите потерянные разделы. Если ФС повреждена, используйте "Полное сканирование" (Full Scan).
4. **Извлечение файлов:** Выделите нужные папки/файлы → Восстановить объект.
5. **Конвертация в VHDX:** В DMDE или DiskGenius: Образ → Конвертировать в VHD/VHDX (Fixed size для WTG).

#### ЭТАП 3: Манипуляции с системой (DISM++ / FRST)
*Цель: Подготовить систему к загрузке на новом железе (WTG).*
1. Смонтируйте полученный `.vhdx` в Windows (ПКМ → Подключить).
2. Запустите **DISM++** (от Администратора).
3. Файл → Восстановить образ → Выберите букву смонтированного VHDX.
4. **Извлечение драйверов:** Панель управления → Драйверы → Экспорт драйверов (в папку на P60).
5. **Очистка:** Используйте DISM++ для очистки мусора, обновления системы, правки реестра.
6. Если система не грузится: запустите **FRST** из WinPE Стрельца, смонтировав VHDX как неактивную ОС (File → Analyze Offline System).

#### ЭТАП 4: Деплой и Виртуализация (Rufus / Bootice / VirtualBox)
*Цель: Запустить систему.*
1. **Для WTG:** Скопируйте `.vhdx` в папку `/WTG/` на P60. Ventoy подхватит его (благодаря `ventoy_vhdboot.img`).
2. **Для ВМ (VirtualBox/VMware):** Создайте новую ВМ, выберите "Использовать существующий виртуальный жесткий диск" → укажите `.vhdx`.
3. **Если не грузится (BSOD 0x0000007B):** Загрузите ВМ с WinPE → запустите **Bootice** → MBR/PBR → Fix Boot → пересоздайте BCD для VHDX.
4. **Для флешки:** Если нужен установочный носитель, используйте **Rufus** для записи ISO/WIM.

### 5. МАТРИЦА ВЫБОРА УТИЛИТЫ (АЛГОРИТМ)

| Ситуация | Действие | Инструмент |
|----------|----------|------------|
| Диск издает щелчки / имеет bad-секторы | Снять поблочный образ | **Rescuezilla** (`ddrescue`) |
| Диск определяется, но разделы "RAW" / исчезли | Восстановить таблицу разделов | **TestDisk** / **DMDE** |
| Нужно достать файлы из `.img` / `.vhdx` | Извлечь файлы с сохранением структуры | **DMDE** / **R-Studio** |
| ФС уничтожена, нужны только фото/документы | Карвинг по сигнатурам | **PhotoRec** |
| Нужно сделать WTG из *здоровой* системы | Горячее клонирование в VHDX | **Hasleo Backup** |
| Нужно достать драйверы / почистить оффлайн-ОС | Работа с WIM/VHDX | **DISM++** |
| Нужно загрузить VHDX на старом BIOS | Правка загрузчика | **Bootice** |

[VALIDATION] ✅ **Чек-лист безопасности**
- [ ] Умирающий диск не монтируется в Windows для чтения файлов.
- [ ] Первый шаг всегда — создание RAW-образа через `ddrescue` (Rescuezilla).
- [ ] Все манипуляции (DMDE, DISM++) проводятся только с образом, а не с физическим диском.
- [ ] Для WTG используется Fixed VHDX на NTFS 64KB (Nexdrive P60).
- [ ] Файл `ventoy_vhdboot.img` присутствует в `/ventoy/` на P60.

**Контекст зафиксирован.** Готов к детализации любого из этапов (например, настройка `ddrescue` в Rescuezilla или работа с DISM++).
