## БЛОКИ 7, 8, 9, 10. ПЕРИФЕРИЙНАЯ ИЗОЛЯЦИЯ (Аудио, COM, Общие папки)

* Аудио (Включить аудио): Выключено (Снято). Защищает от подвисания потоков Sysprep при очистке PnP-дерева звуковых устройств.
* COM-порты (Включить порт): Выключено (Снято). Освобождает ресурсы прерываний (IRQ), предотвращает замусоривание ACPI-таблиц.
* Общие папки: Список абсолютно пуст.
* [EXTENSION PACK INTEGRATION]: Даже при наличии плагина, использование общих папок требует установки пакета Guest Additions. Установка Guest Additions в золотой образ категорически запрещена, так как их ядерные драйверы вмерзают в систему и вызывают BSOD при развертывании образа на реальном железе (Asus, HP, Dell).

## ЧАСТЬ 2. ПОШАГОВЫЙ МАНУАЛ ПО ЛОКАЛЬНОМУ SMB-ОБМЕНУ (ХОСТ <-> ВМ)## Шаг 1. Конфигурация Host-Only сети в VirtualBox 7.2.10

   1. В главном окне VirtualBox выберите Инструменты (Tools) -> Сеть (Network) -> вкладка Виртуальные сети хоста.
   2. Нажмите Создать (Create). Появится адаптер.
   3. Вкладка Адаптер -> Настроить вручную:
   * IPv4 адрес: 192.168.56.1
      * IPv4 маска подсети: 255.255.255.0
   4. Вкладка DHCP-сервер -> Строго Снять галочку «Включить сервер».

## Шаг 2. Развертывание SMB-ресурса на Хост-ПК

   1. На физическом ПК создайте папку: C:\VM_Exchange.
   2. Правой кнопкой мыши по папке -> Свойства -> вкладка Доступ -> Расширенная настройка.
   3. Поставьте галочку «Открыть общий доступ» -> кнопка Разрешения -> группе «Все» выставить: Полный доступ.
   4. Вкладка Безопасность -> Изменить -> Добавить -> ввести Все -> ок. Выставить права: Полный доступ.
   5. Откройте Панель управления -> Центр управления сетями и общим доступом -> Изменить дополнительные параметры общего доступа.
   6. Для всех сетевых профилей (Частная, Общедоступная) Включить сетевое обнаружение и Включить общий доступ к файлам. В разделе «Все сети» Отключить общий доступ с парольной защитой.

## Шаг 3. Настройка сетевого стека внутри гостевой ОС ВМ

   1. Запустите ВМ. Нажмите Win + R -> введите ncpa.cpl.
   2. Правой кнопкой мыши по адаптеру -> Свойства -> IP версии 4 (TCP/IPv4) -> Свойства.
   3. Задайте статические параметры:
   * IP-адрес: 192.168.56.10
      * Маска подсети: 255.255.255.0
      * Основной шлюз: Оставить ПУСТЫМ
      * DNS-сервера: Оставить ПУСТЫМ
      * Результат: ВМ может общаться с хостом, но не имеет путей маршрутизации в интернет. Опасность обновлений AppX заблокирована.
   4. Откройте PowerShell от имени Администратора в ВМ и выполните:
   
   Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private
   
   * Результат: Смена профиля на "Частная" открывает порты брандмауэра ВМ для входящих ответов SMB.
   
## Шаг 4. Подключение сетевой папки как диска

   1. Внутри ВМ откройте командную строку от админа и введите команду маппинга:
   
   net use Z: \\192.168.56.1\VM_Exchange /persistent:no
   
   * Флаг /persistent:no критически важен: он запрещает сохранять диск при перезагрузке, чтобы чистый образ на целевом физическом ПК не зависал при старте службы explorer.exe в поисках хоста 192.168.56.1.
   2. Перенесите все необходимые утилиты, скрипты автоматизации и дистрибутивы на рабочий стол ВМ.
   3. Перед запуском утилиты Sysprep выполните команду полного удаления сетевого следа:
   
   net use Z: /delete

## ЧАСТЬ 3. СПРАВОЧНИК ТРАБЛШУТИНГА (УСТРАНЕНИЕ ОШИБОК СЕТЕВОГО ДОСТУПА)

* «Сетевой путь не найден» (Ошибка 53)
Причина: Брандмауэр Хост-ПК блокирует пакеты на порт TCP 445 со стороны виртуального адаптера.
Решение (На Хост-ПК от админа в PowerShell):

New-NetFirewallRule -DisplayName "VBox_SMB" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 445 -RemoteAddress 192.168.56.0/24

* «Вход в систему не выполнен: ограничение учетной записи» (Ошибка 1326)
Причина: Локальная политика Хоста блокирует сетевой вход учетных записей без пароля.
Решение (Ввод команды в ВМ с явным указанием учетных данных Хоста):

net use Z: \\192.168.56.1\VM_Exchange /user:ИмяПользователяХоста ПарольХоста /persistent:no

* «Политики безопасности блокируют гостевой доступ без проверки подлинности» (Windows 10/11 в ВМ)
Причина: Встроенная защита современных версий Windows запрещает анонимный SMB-вход.
Решение (Внутри ВМ от админа в PowerShell перед подключением папки):

Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters" -Name "AllowInsecureGuestAuth" -Value 1
