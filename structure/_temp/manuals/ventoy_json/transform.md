В логике Ventoy (и GRUB):
• `0` = **Мгновенная загрузка** первого пункта (0 секунд задержки). Это опасно.

Также, параметр `VTOY_FILT_DOT_UNDERSCORE_FILE` скрывает только файлы, начинающиеся с `.` и `_`. На скрине видны `$RECYCLE.BIN` и `System Volume Information`, которые он **не скроет**.

Ниже **исправленная и финальная** версия, которая гарантированно ждёт вашего выбора и убирает системный мусор с экрана.

2. Найдите `Secure Boot` → установите `Disabled`
3. Или: `Secure Boot` → `Custom` → `Enroll Key from Disk` → выберите `EFI/BOOT/grubx64.efi` с флешки

**Сценарий 2: Только UEFI, нет Legacy**
- Ventoy 1.0.90+ поддерживает UEFI из коробки. Убедитесь, что флешка размечена в GPT.

**Сценарий 3: Windows не видит диск при установке**
- В меню установки нажмите `Shift+F10` → введите `diskpart` → `list disk` → если диск есть, проблема в драйверах. Загрузите драйверы контроллера с сайта производителя ноутбука.
