# Цель: 
- создание инженерной инструкции - профессиональный алгоритм действий для создания оптимизированного/отчищенного «золотого образа» с использованием Sophia Script

# Задания:
- проанализируй загруженного скриншота
- дополни/исправь инструкцию там где это нужно
- критически проанализируй полученную инструкцию
- систематизируй результаты анализа
- исправь, дополни, отредактируй там где нужно
- отдай итоговую выверенную инструкцию для создания «золотого образа»





Анализ абсолютно верен. Предыдущая инструкция содержала классические архитектурные ошибки, которые в 100% случаев приводят к провалу создания образа:

   1. Sysprep гарантированно падает в ошибку (Fatal Error), если Магазин (AppX) успел обновиться в фоне или в системе висит отложенная перезагрузка.
   2. Использование урезанного CopyProfile вместо прямого монтирования куста Default User (NTUSER.DAT) ломает кастомизацию интерфейса и забивает профиль мусором из Audit Mode.
   3. Без очистки гостевых дополнений ВМ и сжатия WIM-файла образ получается грязным, избыточным по размеру и аппаратно зависимым.

Ниже представлена критически переработанная, отказоустойчивая и выверенная инструкция для создания «золотого образа» Windows 10/11.
------------------------------
## Пошаговое руководство по созданию «золотого образа» Windows 10/11## Требования к среде:

* Изолированная Виртуальная машина (Hyper-V, VMware или VirtualBox).
* ВАЖНО: Полное физическое отключение сети (отключите виртуальный сетевой адаптер в настройках ВМ). Сети быть не должно до самого конца процедуры.

------------------------------
## Этап 1: Развертывание и вход в Режим Аудита

   1. Запустите установку чистого официального ISO Windows.
   2. На экране первичной настройки (OOBE / Выбор региона) нажмите Ctrl + Shift + F3.
   3. Система перезагрузится во встроенный профиль Администратора.
   4. Появившееся окно Sysprep не закрывайте, а просто сдвиньте в сторону.

------------------------------
## Этап 2: Блокировка фоновой активности и подготовка среды
Прежде чем запускать какие-либо скрипты, необходимо намертво заблокировать механизмы, способные вызвать ошибку Sysprep Syspart. Откройте PowerShell от имени Администратора:

# 1. Жесткая блокировка Центра обновления и Магазина (защита от фонового обновления AppX)
Stop-Service -Name wuauserv, bits, clipsvc, UsoSvc -Force -ErrorAction SilentlyContinue
Set-Service -Name wuauserv, bits, clipsvc, UsoSvc -StartupType Disabled
# 2. Отключение автоматического обновления приложений в реестре
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Orchestrator" -Name "AutoAppUpdate" -Value 0 -Type DWord
# 3. Отключение BitLocker и шифрования устройства (Критично для Win11 24H2+)
Disable-BitLocker -MountPoint "C:" -ErrorAction SilentlyContinue
New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\BitLocker" -Name "PreventDeviceEncryption" -Value 1 -PropertyType DWord -Force

------------------------------
## Этап 3: Фаза глубокой кастомизации и очистки## Фаза А: Разделение работы Sophia Script (Глобальные настройки - HKLM)
Запустите графическую версию SophiApp или отредактируйте файл конфигурации Sophia Script, оставив активными ТОЛЬКО глобальные системные параметры:

* Удаление встроенного мусора (UWP/Bloatware) для всех пользователей.
* Отключение сбора телеметрии, диагностических служб, Cortana, OneDrive.
* Настройка расписаний обслуживания и очистки компонентов.
* Примените скрипт и дождитесь завершения.

## Фаза Б: Прямая кастомизация интерфейса всех будущих пользователей через Default User
Поскольку Sysprep очищает профиль текущего администратора, настройки проводника, контекстных меню и панели задач необходимо внедрить напрямую в эталонный куст реестра:

# 1. Монтируем куст реестра Default User в ветку HKLM
reg load HKLM\DU C:\Users\Default\NTUSER.DAT
# 2. Применяем твики интерфейса (Примеры критических веток, дополняйте по мануалу Sophia Script)# Пример: Отключение Bing-поиска в меню Пуск
reg add "HKLM\DU\Software\Microsoft\Windows\CurrentVersion\Search" /v "BingSearchEnabled" /t REG_DWORD /d 0 /f# Пример: Включение классического контекстного меню в Windows 11
reg add "HKLM\DU\Software\Classes\CLSID\{e2bf9676-5f7f-4474-bc19-0623498a62e6}\InprocServer32" /ve /t REG_SZ /d "" /f
# 3. Размонтируем куст с сохранением изменений (ОБЯЗАТЕЛЬНО)
reg unload HKLM\DU

------------------------------
## Этап 4: Верификация перед запечатыванием
Запуск Sysprep без предварительной проверки — главная причина скрытых сбоев. Проверьте систему по чек-листу в PowerShell:

# 1. Проверка на наличие "зависших" обновлений и требований перезагрузки
$RebootPending = (Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager" -Name "PendingFileRenameOperations" -ErrorAction SilentlyContinue)if ($RebootPending) { Write-Warning "ВНИМАНИЕ: Присутствуют отложенные операции! Перезагрузите ВМ и вернитесь в Audit Mode." }
# 2. Поиск поврежденных/частично установленных пакетов AppX (главный триггер падения Sysprep)
Get-AppxPackage -AllUsers | Where-Object { $_.PackageStatus -match "Paused" -or $_.PackageStatus -notmatch "Ok" -or $_.IsDevelopmentMode -eq $true } | Select Name, PackageFullName# Если команда что-то вернула — удалите эти пакеты вручную через Remove-AppxPackage -AllUsers

## Деинсталляция дополнений гипервизора:
Если вы использовали VirtualBox Guest Additions или VMware Tools для переноса файлов на ВМ, полностью удалите их через «Программы и компоненты» прямо сейчас. Их драйверы привяжут образ к вашей виртуальной машине, вызвав BSOD на реальном железе.
------------------------------
## Этап 5: Предварительная очистка системы (Финализация)
Перед запечатыванием удаляем временные файлы и максимально сжимаем системное хранилище компонентов. В консоли:

# 1. Глубокая очистка базы WinSxS с удалением старых версий пакетов (без возможности отката)
dism /online /cleanup-image /startcomponentcleanup /resetbase
# 2. Удаление файлов дампов, логов и кэша
Remove-Item -Path "C:\Windows\Panther\*" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "C:\Windows\Logs\*" -Recurse -Force -ErrorAction SilentlyContinue
# 3. Отключение файла гибернации (удаляет hiberfil.sys, экономит от 4 до 16 ГБ в образе)
powercfg /h off

------------------------------
## Этап 6: Запечатывание системы (Sysprep)

   1. Откройте окно Sysprep (или выполните команду ниже в PowerShell).
   2. Выполните команду запечатывания с переходом в режим приветствия (OOBE), обязательной очисткой GUID/SID железа (/generalize) и выключением:

C:\Windows\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown

ВМ проведет подготовку и полностью отключится. Включать её в обычной среде больше нельзя.
------------------------------
## Этап 7: Захват и упаковка в ISO

   1. Подключите к виртуальной машине ISO-образ любого аварийного Live-USB (например, WinPE / Sergei Strelec).
   2. Загрузите ВМ с этого Live-USB.
   3. Откройте командную строку и определите точные буквы дисков, так как в среде WinPE они часто меняются:
   
   diskpart
   list volume
   exit
   
   (Допустим, диск с вашей подготовленной Windows определился как буква E:, а флешка/внешний диск для сохранения образа — как D:).
   4. Запустите захват образа с максимальным уровнем сжатия:
   
   dism /Capture-Image /ImageFile:D:\install.wim /CaptureDir:E:\ /Name:"Windows_Gold_v1" /Description:"Clean optimized image" /Compress:max
   
   
## Финал:
Откройте оригинальный официальный дистрибутив Windows в UltraISO. Перейдите в папку sources, удалите стандартный install.wim (или install.esd) и скопируйте туда ваш новый, сжатый install.wim. Сохраните проект в новый ISO-файл.
