## 📝 ПРОМПТЫ-ШАБЛОНЫ

###  **Промпт 1: Начальный анализ утилиты**

```
Проанализируй скриншоты утилиты [НАЗВАНИЕ] версии [ВЕРСИЯ]:

Контекст:
- Моя ОС: Windows 11
- Уровень: beginner (нужны пояснения)
- Цель: освоить диагностику/восстановление/управление
- Песочница: [флешка 4GB / виртуалка / хост]

Задача:
1. Определи тип утилиты (partition manager / backup / recovery / etc.)
2. Составь список всех доступных меню и функций
3. Выдели безопасные функции (только чтение)
4. Выдели критичные функции (изменение данных)
5. Предложи структуру обучения из 7-10 частей

Формат ответа:
- Таблица с меню и их назначением
- Список функций по категориям (безопасные/с изменениями/критичные)
- План обучения с нумерацией уровней

Не давай задания ещё — только анализ и план!
```

### 📚 **Промпт 2: Создание уровней 1-10 (база)**

```
На основе проанализированных скриншотов создай уровни 1-10 для изучения базового функционала [НАЗВАНИЕ УТИЛИТЫ]:

Требования к уровням:
1. Формат таблицы: | # | Уровень (тема/цель) | Навигация | Применение |
2. Уровни 1-5: только просмотр и анализ (безопасные)
3. Уровни 6-10: простые операции на тестовом объекте
4. Для каждого уровня укажи:
   - Точный путь в меню (как на скриншотах)
   - Цель уровня (что научусь делать)
   - Где применять в реальности
   - Предупреждения (если есть риски)

Дополнительно:
- Создай чек-лист "Что должен уметь после уровней 1-10"
- Укажи примерное время на каждый уровень
- Добавь рекомендации по песочнице (что использовать для тестов)

Не давай развёрнутые задания — только оглавление уровней!
```

### 🎯 **Промпт 3: Детальное задание по уровню**

```

Структура задания:
1. Цель уровня (1-2 предложения)
2. Пошаговая инструкция:
   - Точные названия меню/кнопок (как на скриншотах)
   - Ожидаемый результат каждого шага
   - Скриншоты-подсказки (если я загрузил)
3. Предупреждения о безопасности
4. Контрольные вопросы для самопроверки
5. Практическое применение (где пригодится)

Формат:
- Используй нумерованные списки для шагов
- Выделяй ⚠️ критичные моменты
- Добавляй ✅ чек-боксы для отметки выполнения
- Указывай горячие клавиши (если есть)

Контекст:
- Я уже выполнил уровни [ПЕРЕЧИСЛИТЬ]
- Моя тестовая среда: [описание]
- Текущий скриншот: [что показывает]
```

```
3. Работа с образами/бэкапами

- Сложность (1-5 звёзд)
- Необходимые знания из предыдущих уровней

- 2-3 реальных сценария использования

Дополнительно:
- Интеграционный челлендж (уровень 25) — комплексная задача
- Чек-лист компетенций после завершения
- Рекомендации по дальнейшему изучению

Учти ограничения бесплатной версии (если есть)!
```

### 🔍 **Промпт 5: Анализ конкретного окна/диалога**

```
Проанализируй скриншот окна [НАЗВАНИЕ ОКНА] в утилите [НАЗВАНИЕ]:

Задача:
1. Расшифруй все параметры/поля/опции
2. Объясни, что делает каждая галочка/кнопка
3. Рекомендуй безопасные настройки для новичка
4. Укажи, какие параметры критичны (требуют осторожности)
5. Дай примеры использования для разных сценариев

Формат:
- Таблица: | Параметр | Что делает | Рекомендуемое значение | Когда менять |
- Предупреждения ⚠️ для опасных опций
- Примеры настроек для: "быстро", "безопасно", "максимальная производительность"

Контекст:
- Я планирую использовать это для [цель]
- Моя тестовая среда: [описание]
```

```
- Компактно (1-2 страницы A4)

- Только практическая информация

Дополнительно:
- Создай чек-лист безопасности (что проверить перед операцией)

```

## 📊 ОГРАНИЧЕНИЯ И ОПТИМИЗАЦИЯ

### ⚠️ **Что учитывать:**

| Ограничение | Рекомендация |
|------------|--------------|
| **Размер ответа** | Запрашивай по 5-10 уровней за раз, не больше |
| **Контекст** | Напоминай контекст каждые 3-4 сообщения |
| **Скриншоты** | Загружай по 2-3 за раз, не больше 10 в диалоге |
| **Токены** | Сохраняй важные ответы в отдельный файл |

### 💡 **Лайфхаки:**

1. **Сохраняй оглавление** в отдельный файл — оно понадобится для навигации
2. **Нумеруй сообщения** — так легче отслеживать прогресс
3. **Копируй шпаргалки** сразу — контекст может сброситься
4. **Используй короткие промпты** после начального анализа
