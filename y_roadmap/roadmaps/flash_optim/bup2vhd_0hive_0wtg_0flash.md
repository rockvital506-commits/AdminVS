## 1. Оптимизация WTG для снижения износа накопителя

> **Проблема**: При запуске с флешки/внешнего SSD стандартная Windows генерирует тысячи мелких записей (логи, кэш, pagefile), что перегревает контроллер и ускоряет износ ячеек памяти.

### 1.1 Критические отключения (пошагово)

| Компонент | Почему отключать | Как отключить | Эффект |
|-----------|-----------------|---------------|--------|
| **Pagefile.sys** | Постоянная перезапись виртуальной памяти → износ + тормоза при нехватке ОЗУ | `Система → Доп. параметры → Быстродействие → Виртуальная память → Без файла подкачки` | −2…8 ГБ записи/день |
| **System Restore** | Теневые копии весят гигабайты, создаются при каждом обновлении | `Защита системы → Настроить → Отключить` | −1…5 ГБ/неделю |
| **Windows Search** | Фоновая индексация → постоянная активность диска | `services.msc → Windows Search → Отключена` | Снижение фоновой нагрузки на 30–50% |
| **SysMain (SuperFetch)** | Кэширование программ в ОЗУ с предзагрузкой с диска | `services.msc → SysMain → Отключена` | Меньше случайных чтений |
| **Гибернация** | `hiberfil.sys` = размер ОЗУ, записывается при каждом уходе в сон | `powercfg -h off` (админ-консоль) | Освобождает 8–16 ГБ, убирает запись при выключении |
| **Event Log** *(продвинутым)* | Логи пишутся при каждом событии; можно перенаправить в ОЗУ | Реестр: `HKLM\SYSTEM\CurrentControlSet\Services\eventlog` → параметры `File` | Минимизация записи, но риск потери диагностики |

> 💡 **Совет**: Для полной «одноразовости» сессии используйте **Ventoy VHD Snapshot** — состояние сбрасывается при каждой перезагрузке.

### 1.2 Вопросы для уточнения конфигурации
1. Сколько ОЗУ на целевых ПК? (<8 ГБ → pagefile лучше оставить, но ограничить 1–2 ГБ)
2. Нужно ли сохранять данные на флешке после перезагрузки? → если нет, использовать **Persistence = OFF**.

## 5. Обход ограничений Hasleo Free для Pro/LTSC/IoT

> **Проблема**: Начиная с v5.5, Hasleo Free блокирует работу с редакциями Pro/Enterprise/LTSC. Решение: использовать v5.4.2.5 + сторонние утилиты.

### 5.1 Развёртывание бэкапа в VHD (любая редакция)
1. **Смонтировать образ**: Hasleo → Tools → Mount Image → выбрать `.dbi` → получить виртуальный диск `M:`.
2. **Создать пустой VHDX**: WinNTSetup → ПКМ на `VHD` → Создать → указать путь на внешний SSD, формат `VHDX`, тип `Динамический`.
3. **Клонировать файлы**: DiskGenius → Clone Partition → Источник: `M:`, Цель: `V:` (созданный VHDX).
4. **Применить твики загрузки**: Dism++ → Открыть сеанс на `V:` → Оптимизация → включить «Загрузка с USB» (или вручную `BootDriverFlags=14` через Registry Finder).

### 5.2 Чистая установка Windows To Go (Pro/LTSC/IoT) через Ventoy
1. Смонтировать официальный ISO.
2. WinNTSetup → Пункт 1: `install.wim` из ISO.
3. ПКМ на `VHD` → Создать VHDX на внешнем SSD.
4. Выбрать редакцию (Pro / IoT LTSC).
5. **Режим установки**: `VHD-Режим / Windows To Go` (критично!).
6. **Tweaks**: включить «Универсальный загрузочный драйвер USB», отключить TPM/Secure Boot (для совместимости).
7. Setup → UEFI → ОК.

### 5.3 Альтернатива: Rufus (прямая установка, без VHD)
1. Rufus → Устройство: внешний SSD, Образ: ваш ISO.
2. **Image option**: переключить на `Windows To Go`.
3. GPT → Старт → выбрать редакцию → готово.
> ✅ Плюсы: бесплатно, без ограничений, авто-отключение TPM/учётки Microsoft.

## 6. Создание универсального VHDX для загрузки на любом железе

### 6.1 Подготовка Ventoy
- Скачать `ventoy_vhdboot.img` с официального сайта.
- Положить в: `Буква_диска:\ventoy\ventoy_vhdboot.img`.

### 6.2 Три ключевые проблемы и решения
| Проблема | Решение |
|----------|---------|
| Синий экран `INACCESSIBLE_BOOT_DEVICE` на новом железе | Включить раннюю инициализацию USB-драйверов: `BootDriverFlags=14` |
| Привязка к старому железу (после бэкапа) | `Sysprep /generalize` на исходной системе **до** создания бэкапа |
| Конфликт с контроллером Intel VMD (новые ноутбуки) | Интегрировать универсальные драйверы `storahci`/`stornvme` через Dism++ |

### 6.3 Пошагово: из бэкапа → универсальный VHDX
1. Смонтировать бэкап (Hasleo) → диск `M:`.
2. Создать VHDX через WinNTSetup → диск `V:`.
3. Клонировать `M:` → `V:` через DiskGenius.
4. Открыть сеанс `V:` в Dism++ → Оптимизация → включить «Загрузка с USB».
5. При необходимости: добавить универсальные драйверы в раздел «Драйверы».
6. Отсоединить VHDX → готово.

> 💡 **Совет**: Если на новом железе всё равно BSOD — на исходной системе перед бэкапом выполнить `sysprep /generalize /oobe /shutdown`.

## 7. Скрипт оптимизации для WTG (`ssd_optimize.bat`)

```batch
@echo off
chcp 65001 > nul
net session >nul 2>&1
if %errorLevel% == 0 (
    echo [УСПЕХ] Скрипт запущен от имени Администратора. Начинаем оптимизацию...
    echo ---------------------------------------------------------------------
) else (
    echo [ОШИБКА] Запустите ПРАВОЙ КНОПКОЙ МЫШИ -> "Запуск от имени администратора"
    pause & exit /b
)

:: 1. NTFS: не писать время последнего доступа
echo [1/8] Отключение записи времени последнего доступа...
fsutil behavior set disablelastaccess 1

:: 2. Удалить гибернацию
echo [2/8] Удаление hiberfil.sys...
powercfg -h off

:: 3. Отключить прожорливые службы
echo [3/8] Отключение SysMain и Windows Search...
sc config SysMain start= disabled & net stop SysMain >nul 2>&1
sc config WSearch start= disabled & net stop WSearch >nul 2>&1

:: 4. Телеметрия и логи диагностики
echo [4/8] Отключение телеметрии...
sc config DiagTrack start= disabled & net stop DiagTrack >nul 2>&1
sc config dmwappushservice start= disabled & net stop dmwappushservice >nul 2>&1
sc config WerSvc start= disabled & net stop WerSvc >nul 2>&1

:: 5. Планировщик задач: отключение фоновых проверок
echo [5/8] Отключение задач в Планировщике...
schtasks /change /tn "Microsoft\Windows\Application Experience\Microsoft Compatibility Appraiser" /disable >nul 2>&1
schtasks /change /tn "Microsoft\Windows\Application Experience\ProgramDataUpdater" /disable >nul 2>&1
schtasks /change /tn "Microsoft\Windows\Customer Experience Improvement Program\Consolidator" /disable >nul 2>&1
schtasks /change /tn "Microsoft\Windows\DiskDiagnostic\Microsoft-Windows-DiskDiagnosticDataCollector" /disable >nul 2>&1

:: 6. Твики реестра
echo [6/8] Применение твиков реестра...
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CrashControl" /v "CrashDumpEnabled" /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "Start_TrackProgs" /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\ContentDeliveryManager" /v "SilentInstalledAppsEnabled" /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\ContentDeliveryManager" /v "SystemPaneSuggestionsEnabled" /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications" /v "GlobalUserDisabled" /t REG_DWORD /d 1 /f

:: 7. TRIM для SSD
echo [7/8] Активация TRIM...
fsutil behavior set DisableDeleteNotify 0

:: 8. CompactOS: сжатие системных файлов
echo [8/8] Активация CompactOS (2–3 мин)...
compact /compactos:always

echo ---------------------------------------------------------------------
echo [ГОТОВО] Перезагрузите компьютер для применения изменений.
pause
```

### 7.1 Что делает скрипт
| Блок | Эффект | Безопасность |
|------|--------|-------------|
| `disablelastaccess 1` | Не писать время доступа к файлам → меньше записи на диск | ✅ Полностью безопасно |
| `powercfg -h off` | Удаляет `hiberfil.sys` → освобождает 8–16 ГБ | ✅ Безопасно, но отключает гибернацию |
| Отключение `SysMain`/`WSearch` | Снижает фоновую активность на 30–70% | ⚠ Поиск файлов станет медленнее |
| Отключение телеметрии | Убирает скрытую запись логов и сетевую активность | ✅ Безопасно |
| `GlobalUserDisabled=1` | Запрещает фоновый запуск UWP-приложений | ✅ Безопасно |
| `CompactOS` | Сжимает системные файлы → экономия 4–8 ГБ, ускорение чтения на CPU i7 | ✅ Обратимо (`compact /compactos:never`) |

> 💡 **Совет**: Положите `ssd_optimize.bat` в корень внешнего SSD → после первой загрузки новой WTG запустите его от администратора.

## 8. Дополнительные оптимизации свежеустановленной Windows 10/11

### 8.1 Автозагрузка и фоновые приложения
- **Диспетчер задач** → Автозагрузка → отключить всё лишнее (OneDrive, Edge Update, Teams).
- **Фоновые приложения (глобально)**:  
  `reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications" /v "GlobalUserDisabled" /t REG_DWORD /d 1 /f`

### 8.2 Планировщик задач: отключение скрытых проверок
```cmd
taskschd.msc → Библиотека → Microsoft → Windows →
• Application Experience → отключить: Microsoft Compatibility Appraiser, ProgramDataUpdater
• Customer Experience Improvement Program → отключить: Consolidator
• DiskDiagnostic → отключить: Microsoft-Windows-DiskDiagnosticDataCollector
```

### 8.3 Схема питания
- Панель управления → Электропитание → **Высокая производительность**.
- Для максимального отклика (только Pro/Enterprise):  
  `powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61` → выбрать «Максимальная производительность».

### 8.4 HAGS (аппаратное планирование графики)
- Параметры → Система → Дисплей → Графика → Изменение стандартных параметров → ✅ **Планирование с аппаратным ускорением**.

### 8.5 Очистка через CompactOS
```cmd
compact /compactos:query    :: проверить статус
compact /compactos:always   :: включить сжатие (4–8 ГБ экономии)
```
> ✅ На i7-12700H распаковка в ОЗУ происходит быстрее чтения с внешнего SSD → прирост отзывчивости.
