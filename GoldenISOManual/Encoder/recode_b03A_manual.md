Вы абсолютно правы. В финальной инструкции **потеряна логика создания и применения `Recode.ps1`**. 

**Что было неправильно:**

  2. Отредактировать секцию CONFIG (выбрать кодировку, список файлов)

**Логическое противоречие:**
- Если все файлы (Config.psd1, Apply.ps1, Verify.ps1, Rollback.ps1) создаются через `here-string + WriteAllText`, то они **уже в UTF-8 с BOM**

## ✅ Правильная логика: два сценария

### Сценарий A: Все файлы создаются через PowerShell (РЕКОМЕНДУЕТСЯ)

**Workflow:**
```
1. Вставить код ФАЙЛА 1 (Config.psd1) → создаётся в UTF-8 с BOM
2. Вставить код ФАЙЛА 2 (Apply.ps1) → создаётся в UTF-8 с BOM
3. Вставить код ФАЙЛА 3 (Verify.ps1) → создаётся в UTF-8 с BOM
4. Вставить код ФАЙЛА 4 (Rollback.ps1) → создаётся в UTF-8 с BOM
5. Recode.ps1 НЕ НУЖЕН — все файлы уже в правильной кодировке
```

**Когда использовать:** При первом развёртывании блока 03A.

---

### Сценарий B: Файлы созданы вручную через Блокнот (Recode.ps1 НУЖЕН)

**Workflow:**
```
1. Создать файлы вручную через Блокнот (кодировка может быть ANSI/UTF-8 без BOM)
2. Вставить код ФАЙЛА 5 (Recode.ps1) → создаётся в UTF-8 с BOM
3. Открыть Recode.ps1 в Notepad++ или PowerShell ISE
4. Отредактировать секцию CONFIG:
   - Раскомментировать нужную кодировку: $TARGET_ENCODING = 'UTF8-BOM'
   - Указать список файлов: $FILES = @('Apply.ps1', 'Verify.ps1', ...)
5. Сохранить Recode.ps1
6. Запустить: powershell -ExecutionPolicy Bypass -File ".\Recode.ps1"
7. Все файлы из списка перекодируются в UTF-8 с BOM
```

**Когда использовать:** 
- Если вы создали файлы вручную через Блокнот
- Если нужно перекодировать файлы в другой формат (ANSI для .cmd)
- Если кодировка файлов была повреждена

#### 🅱️ Сценарий B: Создание через Recode.ps1 (если файлы созданы вручную)

**Используйте этот сценарий, если вы создали файлы через Блокнот (не через PowerShell).**

Скопируйте **ВЕСЬ код из ФАЙЛА 5** и вставьте в PowerShell. Нажмите Enter.

**Ожидаемый результат:**
```

[+] Отредактируйте секцию CONFIG и запустите:
    powershell -ExecutionPolicy Bypass -File '.\Recode.ps1'
```

##### 2B.2. Отредактировать Recode.ps1

Откройте `Recode.ps1` в **Notepad++** или **PowerShell ISE**.

Найдите секцию `CONFIG` в начале файла:

```powershell
# ==============================================================================
# CONFIG - НАСТРОЙКИ ПЕРЕКОДИРОВАНИЯ
# ==============================================================================

# --- ЦЕЛЕВАЯ КОДИРОВКА (выберите ОДНУ) ---
$TARGET_ENCODING = 'UTF8-BOM'          # UTF-8 с BOM (для .ps1 и .psd1)
# $TARGET_ENCODING = 'UTF8-NOBOM'      # UTF-8 без BOM (для .json, .txt)
# $TARGET_ENCODING = 'ANSI'            # Windows-1251 (для .cmd)

# --- ИСХОДНАЯ КОДИРОВКА ---
$SOURCE_ENCODING = 'AUTO'

# --- ФАЙЛЫ ДЛЯ ПЕРЕКОДИРОВАНИЯ ---
$FILES = @(
    'Apply.ps1',
    'Verify.ps1',
    'Rollback.ps1',
    'Config.psd1'
)
```

**Убедитесь, что:**
- ✅ `$TARGET_ENCODING = 'UTF8-BOM'` (раскомментирована)
- ✅ `$FILES` содержит список файлов, которые нужно перекодировать

Сохраните файл.

### Шаг 4. Предполетная подготовка (Tamper Protection)

**КРИТИЧНО:** Перед запуском Apply.ps1 **обязательно** отключите Tamper Protection вручную:

1. Пуск → **Безопасность Windows** → **Защита от вирусов и угроз**
2. **Управление настройками** → Выключите **Защита от несанкционированного доступа** (Tamper Protection)
3. Если тумблер серый — удалите ключ `DisableAntiSpyware` из реестра:
   ```powershell
   Remove-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows Defender" -Recurse -Force -ErrorAction SilentlyContinue
   ```
4. Перезагрузите ВМ:
   ```powershell
   shutdown /r /t 0
   ```
