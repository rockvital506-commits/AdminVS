## ✅ Доступные функции (управление/восстановление дисков)

### 🔧 Базовые операции с разделами
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Создание / удаление / форматирование разделов | ✅ | Все ФС: NTFS, FAT32, exFAT, ext2/3/4 (чтение) |
| Изменение размера / перемещение | ✅ | Без потери данных, с предпросмотром |
| Слияние разделов (Merge) | ✅ | Включая **несмежные** разделы (уникальная фича) |
| Разделение раздела (Split) | ✅ | С указанием размера нового тома |
| Изменение буквы диска / метки | ✅ | Мгновенно, без перезагрузки |

### 🔄 Конвертация и миграция
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Конвертация MBR ↔ GPT | ✅ | Для **дисков с данными**; системный — с осторожностью |
| Конвертация файловой системы | ✅ | FAT32 ↔ NTFS **без форматирования** |
| Миграция ОС на SSD | ✅ | Клонирование системы с подгонкой под размер целевого диска |
| Выравнивание разделов для SSD | ✅ | Автоматически (кратность 1 МБ) |

### 🔍 Диагностика и восстановление
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Проверка поверхности (Surface Test) | ✅ | Поиск bad-секторов, визуализация |
| Проверка файловой системы | ✅ | Аналог `chkdsk` с GUI |
| Восстановление разделов | ⚠️ | Базовое (поиск потерянных таблиц разделов) |
| Клонирование диска/раздела | ⚠️ | Только **диски с данными** в бесплатных редакциях |

### 🛠️ Дополнительные инструменты
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Создание загрузочного носителя | ✅ | Встроенный мастер (но в WinPE это избыточно) |
| Сброс пароля Windows | ❌ | Отдельная утилита в Стрельце (`NT Password Editor`) |
| Работа с динамическими дисками | ⚠️ | Ограничена в Standard; полная — в Technician/Pro |
| CLI (`partassist.exe`) | ⚠️ | Может быть доступен, зависит от сборки |

## ⚠️ Ограничения этой версии в контексте Strelec WinPE

| Ограничение | Почему важно | Как проверить |
|-------------|-------------|--------------|
| **Неизвестная точная редакция** | Функционал может отличаться от «чистой» Standard/Technician | Запустите → меню «Справка» → «О программе» |
| **Отсутствие онлайн-активации** | В WinPE нет сети по умолчанию → некоторые функции могут быть заблокированы | Проверьте кнопки: если серые — функция недоступна |
| **Зависимость от драйверов контроллера** | Если в WinPE нет драйвера для вашего RAID/NVMe → диск не отобразится | Используйте `Diskpart` или `HWiNFO` для проверки видимости диска |
| **Secure Boot / подпись драйверов** | На некоторых ПК с включённым Secure Boot драйвер AOMEI может не загрузиться | Если программа запускается, но не видит дисков — попробуйте отключить Secure Boot временно |
| **Нет техподдержки** | Сборки Стрельца — неофициальные, баги не фиксируются вендором | Ищите помощь на форумах (usbtor, forums.mydigitallife) [[47]][[49]] |

## 🎯 Практическая проверка (в вашей среде)

```powershell
# 1. Загрузитесь с вашего Ventoy → выберите Strelec ISO
# 2. Откройте: Пуск → Программы → Жёсткий диск → AOMEI Partition Assistant
# 3. Проверьте версию: меню "Справка" → "О программе"
# 4. Протестируйте безопасную операцию:
#    - ПКМ по несистемному разделу → "Свойства"
#    - Убедитесь, что видите: тип ФС, размер кластера, смещение
# 5. НЕ нажимайте "Применить" без понимания последствий
```

> 💡 **Совет:** Если вы планируете использовать AOMEI из Strelec **на чужих ПК** — заранее протестируйте на виртуалке с включённым Secure Boot, чтобы убедиться в совместимости драйверов.

В **Strelec 2026.02.05** также присутствуют:
- **MiniTool Partition Wizard 13.5** (аналогичный функционал) [[19]]
- **EaseUS Partition Master 19.23** (более продвинутый, но англ. интерфейс) [[11]]
- **DiskGenius 6.0** (мощный инструмент + восстановление данных) [[19]]

> 💡 **Стратегия:** Если AOMEI не запустился или не видит дисков → попробуйте **DiskGenius** или **MiniTool** — у них другие драйверы, выше шанс совместимости.
