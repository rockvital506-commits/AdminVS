## Исследования проведены. Систематизация результатов.

---

### Направление исследования 1: Уровни абстракции данных как основа выбора инструмента

Анализ показал, что утилиты работают принципиально на разных уровнях, и выбор неверного уровня делает задачу либо неразрешимой, либо опасно избыточной. Уровни образуют иерархию от физического носителя до логики ОС:

**L0 — физический** → L1 — блочный (секторы) → L2 — разметка (MBR/GPT/разделы) → L3 — файловая система → L4 — файлы/данные → **L5 — ОС/образ/загрузчик**

### Направление исследования 2: Матрица «задача → утилита» — покрытие действий

Выявлено, что ни одна утилита не покрывает все уровни одинаково хорошо. Наиболее универсальны по охвату уровней: **DiskGenius** (L1–L5), **DMDE** (L0–L4), **R-Studio** (L1–L4). Специализированные инструменты доминируют на своём уровне: TestDisk (L2), PhotoRec (L3–L4 через carving), DISM++ (L5), WinNTSetup (L5).

| Параметр | **DiskGenius** ★★★★★ | **FRST** ★★★★★ | **DISM++** ★★★★☆ |
|---|---|---|---|
| Работа в WinRE/WinPE | ✅ | ✅ | ✅ |
| Анализ реестра/сервисов/драйверов | ✅ hex-editor | ✅ детальные отчёты FRST.txt | ✅ управление сервисами |
| Скриптовое исправление | ❌ | ✅ fixlist.txt | ✅ частично |
| Диагностика малвари | ❌ | ✅ (основная цель) | ❌ |
| Управление автозагрузкой | ✅ | ✅ | ✅ |
| Ограничения free-версии | нет | нет (полностью бесплатен) | нет |

---

> **Итоговая мнемоника для выбора инструмента:**
> - Диск умирает → **L0**: DMDE / DiskGenius (образ с bad sectors)
> - Разделы пропали → **L2**: TestDisk / DiskGenius
> - Файлы удалены, ФС жива → **L3**: DiskGenius / R-Studio
> - ФС мёртвая, файлы нужны по типу → **L1 carving**: PhotoRec / DiskGenius
> - Система не грузится (загрузчик) → **L2+L5**: Bootice / DiskGenius / WinNTSetup
> - Нужно развернуть/настроить Windows → **L5**: WinNTSetup / DISM++
> - Полный бэкап системы → **L5+L1**: Hasleo / Rescuezilla
> - Диагностика заражённой Windows → **L5 диагностика**: FRST
