### 🔹 Как работает механизм (пошагово)
1. **Детекция**: `ANALYTICAL_ENGINE` сканирует входной запрос + `HANDOFF Contract` на наличие `USE_CODE: true` или числовых метрик (`latency`, `cost`, `%`, `±`).
2. **Генерация кода**: Если триггер активен → создаётся минимальный скрипт:
   ```python
   # Auto-generated for gap calculation
   target, baseline = 50, 68  # ms
   gap = ((baseline - target) / baseline) * 100
   confidence = 0.92  # from CACHE consensus
   print(f"{gap:.1f}% ± {(1-confidence)*100:.1f}%")
   ```
3. **Исполнение**: `code_interpreter` запускает скрипт в песочнице → возвращает `stdout`.
4. **Инъекция**: Результат парсится и подставляется в `ANALYSIS_REPORT`:
   ```json
   "metrics_gap": [{"metric": "latency", "target": 50, "current": 68, "delta": "-26.5% ± 0.8%", "priority": "HIGH"}]
   ```
5. **Fallback**: Если `code_interpreter` недоступен/ошибка → возврат к эвристике с `[UNVERIFIED]` флагом.

| Задача | Нужен `USE_CODE` | Пример |

| Архитектурные решения | ❌ | Логика > арифметика |

**Почему:**
| Флаг/Параметр | Фаза протокола | Назначение |
|---------------|----------------|------------|

**Как работает генерация кода без флага:**
1. `ROLE ROUTER` детектит `script`/`code` → активирует `ENGINEER`.
2. Пайплайн идёт по `4. PLAN → 5. SELF-CRITIQUE → 6. EXECUTE` → генерирует модульный, документированный код.
3. На шаге `7. VALIDATION CYCLES` → `B. LOGIC_CHECK` может автоматически вызвать `code_interpreter` для проверки синтаксиса/импортов, но это **встроено в протокол**, а не требует ручного флага.

**Когда `USE_CODE: true` всё же уместен при работе с кодом:**
| Ситуация | Нужен флаг? | Зачем |
|----------|-------------|-------|
| "Напиши bash-скрипт бэкапа" | ❌ | Стандартный `ENGINEER` workflow |
| "Рассчитай, сколько воркеров нужно для 10K RPS при CPU 70%" | ✅ | Точный численный gap-анализ до генерации конфига |
| "Сравни сложность O(n²) vs O(n log n) для 1M строк в памяти" | ✅ | Математическая валидация в `ANALYSIS_REPORT` |
| "Проверь сгенерированный Python-код на синтаксис перед выводом" | ❌ | Валидация срабатывает автоматически на шаге 7 |
