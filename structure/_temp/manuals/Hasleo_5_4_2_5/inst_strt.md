
## 1. Подготовка к установке

* **Запуск от имени Администратора:** Hasleo требует привилегий `SeLoadDriverPrivilege` для установки драйвера CBT (`HasleoCBT.sys`) и регистрации собственного VSS Writer. Запуск из обычной учетной записи приведет к тихому отказу установки драйвера, что сломает инкрементальные бэкапы.
* **Проверка статуса VSS:** Введите в PowerShell (Admin): `vssadmin list writers`. Все статусы должны быть `Stable` и `No error`. Если видите `Failed` или `Waiting for completion` — служба теневых копий повреждена. Hasleo не сможет сделать консистентный снимок живой Windows. *Почему критично:* VSS — это "фотокамера" для дисков. Если камера сломана, снимок получится размытым или неполным.
* **Почему не на внешний USB:** Установка на P60/SD400 создаст риски: смена буквы диска при переподключении, случайное отключение во время работы драйвера CBT (приведет к BSOD `DRIVER_IRQL_NOT_LESS_OR_EQUAL`), невозможность запустить восстановление из WinPE (драйверы должны быть в системном реестре).
* **Подготовка целевой папки:** Создайте `P60:\Hasleo\Backups\`. Откройте Свойства папки → Безопасность → Убедитесь, что у `SYSTEM` и `Администраторы` есть `Полный доступ`. Добавьте папку в исключения антивируса/Windows Defender: `Add-Exclusions -Path "P60:\Hasleo\Backups"` (PowerShell). *Зачем:* Антивирус будет сканировать каждый записываемый блок образа в реальном времени, замедляя бэкап в 3-5 раз и вызывая таймауты записи на USB.

## 2. Архитектурный базис (First Principles)

* **VSS (Volume Shadow Copy Service):** Служба Windows, которая в момент запуска бэкапа замораживает файловую систему на микросекунды и создает "теневую копию" (snapshot). Пока Hasleo читает этот снимок, ваша живая система продолжает работать. *Аналогия:* Вы фотографируете бегущего человека с очень короткой выдержкой. На фото человек застыл в идеальной позе, хотя в реальности он продолжает движение. Hasleo читает "застывший кадр", не мешая Windows.
* **CBT (Changed Block Tracking):** Фоновый мини-фильтр ядра, который ведет журнал всех секторов, в которые система произвела запись после последнего бэкапа. При создании инкремента Hasleo не сканирует весь диск, а просто читает этот журнал. *Зачем:* Экономит время (секунды вместо часов) и место (копируются только измененные байты, а не весь диск заново).
* **Block-Level vs File-Level:** File-Level читает данные через API проводника (копирует папки). Block-Level читает диск как массив физических секторов (по 4 КБ), игнорируя файловую систему. Hasleo работает на блочном уровне. *Почему критично для ОС:* Загрузчик (BCD), реестр и системные файлы заблокированы ядром Windows. File-Level скопирует их в открытом/нечитаемом состоянии. Block-Level обходит блокировки, захватывая точное состояние диска на момент VSS-снимка, что гарантирует загрузку после восстановления.

## 5. Проверка работоспособности

1.  **Создание тестового Full-образа:** Вкладка `Главная` → `Новый бэкап` → `Бэкап системы`. Выберите путь `P60:\Hasleo\Backups\Test_Full.hbd`. Сжатие: `Обычное`. Нажмите `Proceed`. Дождитесь `Backup completed successfully`. *Цель:* Проверить работу VSS, CBT (инициализация карты), записи на USB и целостности первого контейнера.
2.  **Верификация целостности:** Вкладка `Инструменты` → `Проверка образа`. Выберите `Test_Full.hbd`. Нажмите `Начать проверку`. Программа побайтово сравнит хэш-суммы записанных данных с исходными секторами. *Цель:* Исключить "тихую порчу" данных при передаче по USB 3.2.
3.  **Тестовое монтирование:** Вкладка `Инструменты` → `Смонтировать/размонтировать образ`. Выберите `Test_Full.hbd`. Нажмите `Смонтировать`. В проводнике появится виртуальный диск (напр., `E:`). Откройте `E:\Windows\System32` — файлы должны читаться. Нажмите `Размонтировать`. *Цель:* Подтвердить, что контейнер `.hbd` структурно цел и Hasleo может извлекать из него данные без полного восстановления.

## 6. Ограничения версии Free (v5.4.2.5)

* **Отсутствие приоритетной техподдержки:** В случае критического сбоя цепочки инкрементов или повреждения `.hbd` контейнера, официальные каналы поддержки отвечают по остаточному принципу. Решение проблем ложится на сообщество/форумы.
* **Ограничения планировщика задач:** Free-версия поддерживает расписание, но не позволяет создавать сложные условия триггеров (например, "только при подключении к сети X" или "при простое CPU > 30 мин"). Бэкапы будут запускаться строго по времени или событию входа в систему.
* **Проприетарный формат без экспорта:** Образы `.hbd` открываются только внутри Hasleo. Вы не можете конвертировать их в стандартный `.vhdx` или `.wim` сторонними утилитами без полного восстановления образа на физический диск.
* **Отсутствие шифрования (в некоторых сборках Free):** Функция AES-256 шифрования образов иногда заблокирована в Free-тире. Если данные чувствительны, используйте BitLocker на самом разделе P60, а не на уровне образа.

## 7. Итоговая рекомендация

После установки сделай эти 3 вещи сразу, чтобы...
1. **Запусти `Восстановление VSS` из вкладки `Инструменты`.** Это гарантирует, что "камера" Windows исправна и первый же бэкап не упадет с ошибкой доступа к заблокированным файлам реестра.
2. **Создай папку `P60:\Hasleo\Backups\` и добавь её в исключения Defender.** Это предотвратит конфликты I/O на шине USB 3.2, которые часто приводят к тихому повреждению цепочек инкрементов.
3. **Выполни тестовый цикл: Full → Verify → Mount.** Не создавай первую стратегию бэкапов на "боевой" системе. Убедись, что Hasleo может смонтировать образ и прочитать файлы — это твоя страховка от ситуации "бэкап есть, но восстановить нельзя".

# 1. Подготовка к установке

## Чек-лист перед запуском Hasleo Backup Suite Free v5.4.2.5

### □ Проверить состояние файловой системы

Открой командную строку от администратора:

```cmd
chkdsk C: /scan
```

### Почему это важно

Любой backup работает по принципу:

```text
Garbage In → Garbage Out
```

Если NTFS уже содержит повреждения:

```text
битые ссылки MFT
ошибки индексов
битые security descriptors
```

они попадут в образ.

---

### □ Запускать установщик строго от имени администратора

ПКМ по EXE:

```text
Запуск от имени администратора
```

### Почему это важно

Во время установки Hasleo добавляет:

```text
Службы Windows
VSS-компоненты
Драйвер CBT
WinPE-компоненты
Фильтры ввода-вывода
```

Без Administrator часть компонентов может установиться некорректно.

Результат:

```text
Backup работает
Incremental не работает
или
CBT не активируется
```

---

### □ Проверить работоспособность VSS

Открыть CMD от администратора:

```cmd
vssadmin list writers
```

Нормальное состояние:

```text
State: Stable
No error
```

для всех Writers.

---

### Почему VSS критичен

Hasleo делает backup работающей Windows.

Без VSS:

```text
Outlook открыт
Chrome открыт
Реестр меняется
База OneDrive меняется
```

получится логически поврежденный образ.

---

### □ Проверить свободное место

Для первого Full Backup рекомендуется:

```text
Свободно ≥ 1.5 размера занятого пространства Windows
```

Пример:

```text
На NVMe занято 120 ГБ

Минимум:
180 ГБ свободно
```

---

### □ Создать каталог хранения

На P60:

```text
P:\Hasleo\
P:\Hasleo\Backups\
P:\Hasleo\Images\
```

---

### □ Исключения антивируса

Добавить исключения:

```text
P:\Hasleo\
```

и после установки:

```text
C:\Program Files\Hasleo\
```

---

### Почему это важно

Во время backup антивирус начинает:

```text
сканировать каждый блок
сканировать каждый ADI-файл
```

что может снизить скорость на 20-50%.

---

### □ Не устанавливать Hasleo на P60 или SD400

Правильно:

```text
C:\Program Files\Hasleo\
```

Неправильно:

```text
P:\Programs\Hasleo\
```

---

### Почему

Службы запускаются еще до подключения USB.

Если программа установлена на внешний диск:

```text
служба не стартует
CBT не загрузится
WinPE Builder может работать некорректно
```

# 2. Архитектурный базис (First Principles)

## VSS (Volume Shadow Copy Service)

### Что это

Служба моментального снимка тома Windows.

---

### Аналогия

Представь библиотеку.

Пока читатели работают:

```text
берут книги
возвращают книги
меняют закладки
```

архивист делает фотографию всей библиотеки.

После снимка:

```text
люди продолжают работать
```

но архивист уже работает с замороженной копией.

---

### Что делает VSS

Hasleo говорит Windows:

```text
Создай Shadow Copy диска C:
```

Windows создает:

```text
консистентный снимок файловой системы
```

После этого Hasleo читает снимок.

Не живой диск.

---

## CBT (Changed Block Tracking)

### Что это

Низкоуровневый драйвер отслеживания измененных блоков.

---

### Без CBT

После Full Backup:

```text
120 ГБ данных
```

Hasleo снова анализирует:

```text
все 120 ГБ
```

чтобы найти изменения.

---

### С CBT

Драйвер запоминает:

```text
Блок 500 изменился
Блок 700 изменился
Блок 950 изменился
```

При следующем backup:

```text
считываются только измененные блоки
```

---

### Почему это экономит время

Пример:

```text
Система = 120 ГБ

Изменилось = 800 МБ
```

Без CBT:

```text
анализ 120 ГБ
```

С CBT:

```text
анализ 800 МБ
```

---

## Block-Level Backup

### Что копируется

Не файлы.

Копируются блоки.

Пример:

```text
EFI
GPT
BCD
MFT
NTFS Metadata
Windows
```

---

### Почему это важно

Можно восстановить:

```text
полностью загрузочную систему
```

включая:

```text
UEFI
Boot Manager
Recovery
```

---

## File-Level Backup

Копируются файлы:

```text
*.docx
*.jpg
*.exe
```

---

### Недостаток

Нельзя гарантированно восстановить:

```text
загрузчик
EFI
BCD
```

---

### Почему Hasleo использует Block-Level

Для системного восстановления это единственный надежный способ.

# 6. Ограничения версии Free (v5.4.2.5)

Для домашних пользователей Free-версия достаточно функциональна, но есть ограничения.

### Ограничения

* Нет приоритетной технической поддержки.
* Нет коммерческого лицензирования.
* Некоторые корпоративные сценарии управления отсутствуют.
* Нет централизованной консоли управления несколькими ПК.
* Нет серверных лицензий Windows Server.
* Нет части enterprise-функций, связанных с корпоративным развертыванием и управлением инфраструктурой.

---

### Чего Free хватает полностью

```text
System Backup
Disk Backup
Partition Backup
Incremental
Differential
Compression
Restore
Clone
WinPE
```

Для твоего комплекса:

```text
ASUS Vivobook
P60
SD400
Ventoy
WTG
```

ограничения Free практически не мешают.

# 7. Итоговая рекомендация

Сразу после установки сделай три вещи:

### 1

Проверь:

```cmd
vssadmin list writers
```

Все должны быть:

```text
Stable
No Error
```

---

### 2

Создай:

```text
P:\Hasleo\Backups\
```

и используй P60 как основное хранилище всех рабочих образов.

---

### 3

Создай тестовый Full Backup + Verify + Mount.

Только после успешного прохождения этих трех проверок имеет смысл строить постоянную схему:

```text
Ежемесячно:
Full

Еженедельно:
Differential

Перед опасными экспериментами:
Отдельный Full
```

Это дает лучший баланс между скоростью создания, надежностью восстановления и простотой сопровождения для твоей инженерной сборки.
