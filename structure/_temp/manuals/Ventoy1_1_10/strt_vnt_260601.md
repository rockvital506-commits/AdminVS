[PHASE 0] 🔍 **Анализ:** тип=`configure` | сложность=4/5 | домены=`Storage/Boot/FS`
1. **Очистка диска:** Ventoy **не гарантирует** полную очистку скрытых служебных разделов/остатков MBR→GPT. Для стабильного загрузчика и корректного выравнивания **обязательна ручная очистка** перед установкой.
2. **Оптимальная подготовка:** `Clean GPT` → `2MB Alignment` → `Install Ventoy (Partition 2)` → `Reformat P2 to exact cluster` → `Create P3 (Tools)`. Ventoy GUI не всегда применяет кастомный размер кластера при установке, поэтому форматирование P2 лучше выполнить в DiskGenius *после* записи загрузчика.

## Ответ2(всего 2 ответа):

## Ответ на главный вопрос

**Нет, вручную чистить диск заранее не нужно.** Ventoy при установке полностью перезаписывает MBR/GPT и создаёт свои разделы сам. Но есть нюанс: Ventoy создаёт только два своих раздела (VTOYEFI + один большой раздел данных). Третий раздел (`Soft`, NTFS 4K) Ventoy не создаёт — его нужно добавить вручную через DiskGenius до или после установки Ventoy. Оптимальный порядок описан ниже.

---

## Пошаговый план — Nexdrive P60

### Фаза 0 — Подготовка Windows перед началом

1. Открой `Диспетчер устройств` → найди диск → `Свойства` → вкладка `Политика` → выбери **"Оптимальная производительность"** (включает кэш записи). Это нужно сделать до форматирования.
2. Убедись, что в системе включён UASP: в том же диспетчере устройство должно отображаться как `USB Attached SCSI (UAS) Mass Storage`, а не просто `USB Mass Storage Device`. Если нет — переподключи в порт USB 3.2 Gen 2 напрямую, без хабов.

---

### Фаза 1 — Ventoy: установка с правильными параметрами

> Ventoy создаст раздел 1 (VTOYEFI, FAT32) и раздел 2 (данные). Размер раздела 2 мы зафиксируем на шаге Фазы 2 через DiskGenius.

1. Запусти `Ventoy2Disk.exe` от имени администратора.
2. В меню сверху: `Option` → `Partition Style` → выбери **GPT**.
3. `Option` → `Partition Configuration`:
   - `Reserve space at the end of disk` → введи **`122880`** МБ (≈120 ГБ — место под раздел 3 `Soft`).
   - Убедись что опция "Reserve space" включена.
4. Выбери диск Nexdrive P60 в выпадающем списке.
5. Нажми **Install** → подтверди оба предупреждения.
6. Ventoy создаст: `VTOYEFI` (~32 МБ FAT32) + большой раздел данных (~348 ГБ, exFAT по умолчанию).

---

### Фаза 2 — DiskGenius: переформатирование раздела 2 + создание раздела 3

> Ventoy форматирует свой раздел данных в exFAT. Для P60 нам нужен NTFS с кластером 64 КБ. Переформатируем.

1. Запусти `DiskGenius` от имени администратора.
2. Найди диск P60 на панели слева. Убедись, что видишь 3 элемента: `VTOYEFI` + большой раздел + нераспределённое пространство ~120 ГБ.
3. **Настройка выравнивания (критично — делается один раз для диска):**
   - `Disk` (верхнее меню) → `Set Disk Alignment Sectors Count` → введи **`4096`** (= 2 МБ выравнивание).
4. **Переформатирование раздела 2 (Ventoy-данные):**
   - Кликни правой кнопкой на большом разделе (exFAT, ~348 ГБ).
   - `Format Current Partition` → в окне:
     - File System: **NTFS**
     - Cluster Size: **65536** (64 КБ)
     - Volume Label: `Ventoy` (обязательно — Ventoy ищет раздел по метке)
     - Галочку "Quick Format" — **снять** (полный формат для проверки секторов).
   - OK → подтверди.
5. **Создание раздела 3 (Soft):**
   - Кликни правой кнопкой на нераспределённом пространстве (~120 ГБ) → `Create New Partition`.
   - File System: **NTFS**
   - Cluster Size: **4096** (4 КБ)
   - Volume Label: `Soft_P60`
   - Partition Type: Primary
   - Size: всё доступное пространство.
   - OK.
6. Нажми **Save All** (зелёная кнопка вверху) → подтверди операции.

---

### Фаза 3 — Финальные настройки P60 в Windows

1. Открой `Этот компьютер` → для каждого из двух новых разделов (Ventoy + Soft_P60):
   - ПКМ → `Свойства` → вкладка `Общие` → **снять галочку** "Разрешить индексировать содержимое файлов на этом диске".
   - Применить → "К этой папке, вложенным папкам и файлам".
2. Для раздела `Ventoy` (NTFS 64K): раздел готов к приёму VHDX-контейнеров.
3. Для раздела `Soft_P60` (NTFS 4K): можно включить **встроенное NTFS-сжатие тома**:
   - ПКМ → `Свойства` → "Сжать диск для экономии места" → применить.
   - Работает только потому что кластер = 4 КБ (алгоритм LZNT1 поддерживается).

---

## Пошаговый план — SD400 Pendrive

### Фаза 0 — Политика записи

- Диспетчер устройств → SD400 → `Свойства` → `Политика` → **"Быстрое удаление"** (без кэша — защита данных при внезапном извлечении).

---

### Фаза 1 — Ventoy: установка

1. Запусти `Ventoy2Disk.exe` от имени администратора.
2. `Option` → `Partition Style` → **GPT**.
3. `Option` → `Partition Configuration`:
   - `Reserve space at the end of disk` → **`122880`** МБ (~120 ГБ под раздел 3).
4. Выбери диск SD400.
5. **Install** → подтвердить.

---

### Фаза 2 — DiskGenius: раздел 2 переформатируем в exFAT + создаём раздел 3

1. Запусти DiskGenius.
2. Для диска SD400: `Disk` → `Set Disk Alignment Sectors Count` → **`4096`**.
3. **Переформатирование раздела 2:**
   - ПКМ на большом разделе → `Format Current Partition`:
     - File System: **exFAT**
     - Cluster Size: **524288** (512 КБ)
     - Volume Label: `Ventoy`
     - Quick Format: **снять**.
   - OK.
4. **Создание раздела 3:**
   - ПКМ на нераспределённом → `Create New Partition`:
     - File System: **NTFS**
     - Cluster Size: **4096** (4 КБ)
     - Volume Label: `Soft_SD400`
   - OK.
5. **Save All** → подтвердить.

---

### Фаза 3 — Финальные настройки SD400

1. Отключить индексацию на обоих разделах — аналогично P60.
2. Раздел `Soft_SD400` (NTFS 4K): при желании можно включить NTFS-сжатие тома (те же условия — кластер 4 КБ).
3. Раздел `Ventoy` (exFAT): NTFS-сжатие **недоступно** и не нужно — здесь только монолитные ISO.

🔄 **Нужны ли разные `ventoy.json` для P60 и SD400?**

**Нет, JSON остаётся единым.** Различия обрабатываются на уровне:
1. **Файловой системы** (NTFS на P60 / exFAT на SD400) — Ventoy определяет автоматически.

3. **Версии Windows в образах** — если на SD400 хранятся старые ISO (<v1809), они не загрузятся с VHDX на exFAT (ограничение Microsoft, не Ventoy).

- Не занимает места (~10-20 MB)
- Не влияет на загрузку ISO/WinPE/Linux
