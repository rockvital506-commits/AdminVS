## 📊 Анализ интерфейса DiskGenius V6.2.0

### 🗂️ Структура меню (что где находится):

| Меню | Основной функционал | Горячие клавиши |
|------|-------------------|----------------|
| **Файл(F)** | Работа с файлами, копирование, экспорт | - |
| **Диск(D)** | Управление дисками, таблицы разделов, SMART, бэкапы | F2, F3, F6, F8 |
| **Раздел(P)** | Все операции с разделами (создать, удалить, resize) | F4, F5, F7, F11, Ctrl+F11, Ctrl+F12 |
| **Инструменты(T)** | Восстановление, клонирование, миграция, тесты | F12 |
| **Просмотр(V)** | Настройка интерфейса, язык | - |
| **Справка(H)** | Помощь и документация | - |

## 🎯 ПРАКТИЧЕСКИЕ ЗАДАНИЯ для DiskGenius

### **Уровень 1: Ознакомление (Безопасно - только просмотр)**

#### ✅ Задание 1.1: Изучение интерфейса
```
Цель: Понять, где какая информация отображается

Шаги:
1. Откройте меню "Просмотр(V)" → убедитесь, что отмечено:
   ☑ Панель инструментов
   ☑ Строка состояния
   ☑ Схема дисков и разделов
   ☑ Дерево разделов и папок

2. В левой панели найдите:
   - HD0: SAMSUNG (ваш SSD)
   - HD1: CUSUSD400 (ваша флешка Ventoy)
   - RD2: JetFlashTranscend4GB (ваша тестовая флешка Q:)

3. Кликните на Q_Test(Q:) → изучите нижнюю панель:
   - Файловая система: NTFS
   - Емкость: 3.74GB
   - Размер кластера: 4096
   - Стартовый сектор: 128

Результат: Понимание структуры программы
```

#### ✅ Задание 1.2: Проверка SMART
```
Цель: Узнать состояние здоровья вашего SSD

Шаги:
1. В левой панели выберите HD0: SAMSUNG MZVL4512HBLU
2. Меню "Диск(D)" → "Просмотр информации S.M.A.R.T.(S)"
3. Изучите таблицу:
   - Ищите строки со статусом "Хорошо" (зеленые)
   - Обратите внимание на:
     • 05 - переназначенные сектора
     • C7 - ошибки интерфейса
     • 09 - время наработки

4. Сделайте скриншот (PrintScreen) → сохраните в 
   W:\DATA\Learning\DiskGenius\SMART_screenshot.png

Результат: Понимание, как проверить здоровье диска
```

#### ✅ Задание 1.3: Просмотр свойств раздела
```
Цель: Изучить детальную информацию о разделе

Шаги:
1. Выберите раздел Q_Test(Q:) в левой панели
2. ПКМ по разделу → "Свойства" (или просто изучите нижнюю панель)
3. Найдите и запишите в блокнот:
   - Метка тома: Q_Test
   - ID тома: 2E50-E33A-50E3-0783
   - Версия NTFS: 3.1
   - Всего байт: 4013948928
   - Свободное пространство: 3.72GB
   - Всего секторов: 7839744
   - Размер сектора: 512 Bytes

4. Сравните с выводом в diskpart:
   - Откройте PowerShell → diskpart → list volume
   - Найдите том Q: → сравните размер

Результат: Умение читать технические параметры
```

### **Уровень 2: Безопасные операции (на флешке)**

#### ✅ Задание 2.1: Создание нового раздела
```
Цель: Научиться создавать разделы

⚠️ ВАЖНО: Работаем ТОЛЬКО с флешкой RD2 (4GB)!

   - Размер: 1024 MB (1 GB)
   - Тип раздела: Основной
   - Файловая система: FAT32
   - Метка тома: TEST_PART1
   
4. НЕ нажимайте "OK" сразу!
5. Сделайте скриншот окна создания
6. Закройте окно (отмена)

Результат: Понимание процесса создания раздела
Примечание: Мы не применяем, только изучаем интерфейс
```

#### ✅ Задание 2.2: Проверка выравнивания
```
Цель: Убедиться, что разделы выровнены по 4K

Шаги:
1. Меню "Инструменты(T)" → "Обнаружение выравнивания разделов по 4 КБ"
2. Выберите диск RD2 (ваша флешка)
3. Нажмите "OK"
4. Изучите результат:
   - Должно быть: "Выравнивание: OK"
   - Смещение: кратно 4096 байт

5. Для раздела Q_Test(Q:) проверьте:
   - Стартовый сектор: 128
   - 128 × 512 = 65536 байт = 64 KB (кратно 4K ✅)

Результат: Понимание важности выравнивания для SSD
```

Цель: Понять, как работает resize

Шаги:
1. Выберите раздел Q_Test(Q:)
2. Меню "Раздел(P)" → "Изменение размера раздела(Ctrl+F11)"
3. Изучите окно:
   - Текущий размер: 3.74 GB
   - Минимальный размер: (покажет программа)
   - Максимальный размер: 3.74 GB
   
4. Попробуйте подвигать ползунок:
   - Установите новый размер: 2048 MB
   - Посмотрите, как изменится "Свободное место после"
   
5. НЕ нажимайте "OK"!

### **Уровень 4: Диагностика**

#### ✅ Задание 4.1: Тест скорости диска
```
Цель: Измерить скорость вашей флешки

Шаги:
1. Меню "Диск(D)" → "Тест скорости диска"
2. Выберите RD2 (флешка 4GB)
3. Нажмите "Начать тест"
4. Дождитесь завершения (~30 сек)
5. Изучите график:
   - Последовательное чтение: ___ MB/s
   - Последовательная запись: ___ MB/s
   - Случайное чтение 4K: ___ MB/s
   
6. Сделайте скриншот → сохраните

Результат: Понимание производительности накопителя
```

#### ✅ Задание 4.2: Проверка поверхности (быстрая)
```
Цель: Найти bad-сектора на флешке

Шаги:
1. Меню "Диск(D)" → "Проверка или восстановление поврежденных секторов(V)"
2. Выберите RD2 (флешка)
3. Нажмите "Начать проверку"
4. Наблюдайте за процессом:
   - Зеленые блоки = OK
   - Красные блоки = повреждены
   
5. Для флешки 4GB тест займет ~2-3 минуты
6. По завершении:
   - Если все зеленые → отлично
   - Если есть красные → запишите адреса секторов

Результат: Умение диагностировать физическое состояние
```

### 🟢 Уровень 6: Полный цикл работы с разделами (Создание/Удаление)

**Цель:** Научиться превращать диск в "Нераспределенное пространство" и создавать раздел заново.

#### ✅ Задание 6.1: Удаление и создание раздела
```text
1. Подготовьте флешку:
   - В проводнике Windows удалите все файлы с диска Q: (чтобы не жалко).
   
2. Удаление текущего раздела:
   - В DiskGenius выделите раздел Q_Test(Q:) на флешке (RD2).
   - Меню "Раздел(P)" → "Удалить текущий раздел(Del)".
   - Подтвердите удаление.
   - ⚠️ Результат в интерфейсе: Раздел станет серым с надписью "Свободно" (Free).
   - 🛑 ИЗМЕНЕНИЯ ПОКА НЕ ПРИМЕНЕНЫ!

3. Применение изменений (Первый раз!):
   - Нажмите кнопку "Сохранить всё" (иконка дискеты 💾 в тулбаре слева).
   - Подтвердите операцию.
   - Дождитесь прогресс-бара.

4. Создание нового раздела:
   - Выделите серую полосу "Свободно".
   - Меню "Раздел(P)" → "Создание нового раздела(N)".
   - В окне выберите:
     • Тип: Основной
     • ФС: exFAT (чтобы отличалось от прошлого NTFS)
     • Размер: 2048 MB (оставьте 2 ГБ свободными)
   - Нажмите ОК.
   - Нажмите "Сохранить всё" .

5. Проверка:
   - Откройте "Этот компьютер". Появился ли диск на 2 ГБ?
```

#### ✅ Задание 6.2: Манипуляции с "Свободным местом"
```text
1. Выделите серую область "Свободно" (те 2 ГБ, что остались).
2. ПКМ → "Создать новый раздел".
3. Создайте второй раздел на оставшееся место (FAT32).
4. Нажмите "Сохранить всё" 💾.
5. Результат: На флешке теперь ДВА раздела.
```

### 🟡 Уровень 7: Изменение размера (Resize) — Самая частая операция

**Цель:** Увеличить один раздел за счет другого или свободного места.

#### ✅ Задание 7.1: Расширение раздела
```text
1. Представим, что нам мало места на первом разделе (exFAT).
2. Удалите ВТОРОЙ раздел (FAT32), чтобы освободить место рядом.
   (Раздел(P) → Удалить → Сохранить всё 💾).
   
3. Теперь выделите ПЕРВЫЙ раздел (exFAT).
4. Меню "Раздел(P)" → "Изменение размера раздела(Ctrl+F11)".
5. В окне:
   - Потяните правую границу ползунка до конца (вправо).
   - Или введите в поле "Размер" всё доступное значение.
6. Нажмите ОК.
7. Нажмите "Сохранить всё" 💾.

📝 Результат: Первый раздел "съел" освободившееся место без потери данных (так как файлов там нет).
```

###  Уровень 8: Восстановление данных (File Recovery)

**Цель:** Понять, как DiskGenius находит удаленные файлы.

#### ✅ Задание 8.1: Симуляция потери данных
```text
1. Создайте на флешке (диск exFAT) текстовый файл "SECRET.txt".
   - Напишите внутри: "ЭТО ВАЖНЫЕ ДАННЫЕ".
   - Сохраните.
   
2. Удалите файл "жестко":
   - Выделите файл → Shift + Delete → Да.
   - (Файл исчез из проводника).

3. Запуск восстановления:
   - В DiskGenius выделите раздел с флешки.
   - Меню "Инструменты(T)" → "Восстановить потерянные файлы(U)".
   
4. Настройка сканирования:
   - Выберите "Восстановить файлы" (обычно первый пункт).
   - Нажмите "Начать".
   
5. Процесс:
   - Ждите окончания сканирования.
   - В левой панели (дерево) появится папка "Все файлы" или "Lost Files".
   - Раскройте её → найдите "SECRET.txt".
   
6. Проверка содержимого:
   - Дважды кликните по файлу в DiskGenius → он должен открыться.
   
7. Сохранение (ВАЖНО):
   - ПКМ по найденному файлу → "Копировать в..."
   - Выберите РАБОЧИЙ СТОЛ (не флешку!).
   - Откройте файл на рабочем столе → текст на месте?
```

### 🔴 Уровень 9: Поиск потерянных разделов (Partition Recovery)

**Цель:** Увидеть, как программа ищет "потерянную" таблицу разделов (аналог TestDisk).

#### ✅ Задание 9.1: Поиск существующих разделов
```text
1. Это безопасная процедура (только чтение).
2. Выделите САМУ ФЛЕШКУ (RD2, строку с моделью, а не раздел).
3. Меню "Инструменты(T)" → "Поиск потерянных разделов (восстановление разделов)(L)".
4. Нажмите "Начать поиск".
5. Наблюдайте:
   - Программа будет сканировать цилиндр за цилиндром.
   - Когда найдет раздел, появится окно с вопросом: "Раздел найден, сохранить?"
   - ⚠️ Нажмите "Игнорировать" (Ignore) или "Пропустить".
   - Нам пока нужно просто увидеть, что он НАШЕЛ ваши разделы.
   
6. После завершения сканирования закройте окно.
```
