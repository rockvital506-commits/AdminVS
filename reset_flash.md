## 🔧 Восстановление флешки к исходному состоянию (1 раздел)

### ⚠️ КРИТИЧЕСКИ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

```
┌─────────────────────────────────────────────────────────────────┐
│  ⛔ ВНИМАНИЕ: Все данные на флешке будут ПОЛНОСТЬЮ УДАЛЕНЫ!    │
├─────────────────────────────────────────────────────────────────┤
│  • Убедитесь что выбрали ПРАВИЛЬНЫЙ диск                       │
│  • Не перепутайте с жёстким диском системы!                    │
│  • Закройте все программы работающие с USB                     │
└─────────────────────────────────────────────────────────────────┘
```

---

### 📋 Почему флешка отображается как 2 диска?

Ventoy создаёт **два раздела**:
| Раздел | Размер | Назначение |
|--------|--------|------------|
| **Раздел 1** | ~32 МБ | Загрузчик Ventoy (EFI + Legacy) |
| **Раздел 2** | Остальное пространство | Данные (ISO, файлы) |

Windows присваивает букву каждому разделу → E: и F:

## 🛠️ СПОСОБ 1: DiskPart (Рекомендуемый, полный сброс)

### Пошаговая инструкция:

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 1: Запуск DiskPart от имени администратора                │
└─────────────────────────────────────────────────────────────────┘
```

1. **Нажмите Win + X** → выберите **Терминал (Администратор)** или **PowerShell (Администратор)**
2. **Введите команду:**
   ```
   diskpart
   ```
3. **Нажмите Enter** (подтвердите UAC если появится)

---

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 2: Отобразить все диски в системе                         │
└─────────────────────────────────────────────────────────────────┘
```

4. **Введите команду:**
   ```
   list disk
   ```
5. **Найдите вашу флешку по размеру:**
   ```
   ###  Диск        Размер   Свободно   Динам   GPT
   0    Диск 0      476 ГБ   50 ГБ              *
   1    Диск 1      477 ГБ   0 ГБ               *
   2    Диск 2      512 ГБ   0 ГБ               *   ← Ваша флешка 512 ГБ
   ```

**⚠️ КРИТИЧЕСКИ ВАЖНО:** Не перепутайте номер диска! Ориентируйтесь на **размер 512 ГБ**.

---

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 3: Выбрать флешку и очистить полностью                    │
└─────────────────────────────────────────────────────────────────┘
```

6. **Введите команды по порядку** (замените `2` на ваш номер диска):
   ```
   select disk 2
   clean
   convert gpt
   create partition primary
   format fs=exfat quick label="FLASH_TEST"
   assign letter=F
   exit
   ```

**Полный скрипт для копирования:**
```batch
diskpart
select disk 2
clean
convert gpt
create partition primary
format fs=exfat quick label="FLASH_TEST"
assign letter=F
exit
```

---

### 📊 Описание каждой команды:

| Команда | Назначение | Почему именно так |
|---------|------------|-------------------|
| `select disk 2` | Выбор флешки | Номер может отличаться! |
| `clean` | **Полное удаление всех разделов** | Удаляет таблицу разделов полностью |
| `convert gpt` | Создание GPT таблицы | Требуется для Ventoy + UEFI |
| `create partition primary` | Создание одного раздела | Объединяет всё пространство |
| `format fs=exfat quick` | Быстрое форматирование | exFAT для совместимости |
| `label="FLASH_TEST"` | Метка тома | Для идентификации |
| `assign letter=F` | Назначение буквы | Будет одна буква вместо двух |

## 🛠️ СПОСОБ 2: Управление дисками (Графический интерфейс)

Если предпочитаете GUI вместо командной строки:

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 1: Открыть Управление дисками                             │
└─────────────────────────────────────────────────────────────────┘
```

1. **Нажмите Win + X** → выберите **Управление дисками**
2. **Или:** Win + R → введите `diskmgmt.msc` → Enter

---

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 2: Найти флешку и удалить разделы                         │
└─────────────────────────────────────────────────────────────────┘
```

3. **Найдите флешку** (ориентир: 512 ГБ, съёмное устройство)
4. **ПКМ на каждом разделе флешки** → **Удалить том**
5. **Повторите для всех разделов** пока не останется "Нераспределённая область"

---

```
┌─────────────────────────────────────────────────────────────────┐
│  Шаг 3: Создать один новый раздел                              │
└─────────────────────────────────────────────────────────────────┘
```

6. **ПКМ на нераспределённой области** → **Создать простой том**
7. **Мастер создания томов:**
   - Размер: **Максимальный** (по умолчанию)
   - Буква диска: **Выберите одну (F:)**
   - Файловая система: **exFAT**
   - Метка тома: **FLASH_TEST**
8. **Нажмите Готово**
