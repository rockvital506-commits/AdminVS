[MAIN] Техническое решение

### 🔬 Направление 1: Производительность и надёжность сканирования
**Цель:** Ускорить генерацию меню и предотвратить ошибки парсинга на 476GB носителе.
**Результаты:**
• `VTOY_MAX_SEARCH_LEVEL` > 3 даёт экспоненциальный рост времени скана. Оптимум: `2`.
• `VTOY_FILT_DOT_UNDERSCORE_FILE: true` отфильтровывает системные/временные файлы (`Thumbs.db`, `._macos`, `~$`), которые Ventoy пытается парсить как ISO.
• `VTOY_SORT_CASE_SENSITIVE: false` + `VTOY_SORT_LETTER_FIRST: true` упорядочивает список без ручного префикса `1_`, `2_`.
• `VTOY_DEFAULT_SEARCH_ROOT: "/ISOs"` принудительно ограничивает скан одной папкой, игнорируя W: и служебные каталоги.

### 🔬 Направление 2: Автоматизация и персистенс в split-архитектуре
**Цель:** Настроить live-сессию с сохранением данных и автоустановку без вмешательства.
**Результаты:**
• `persistence.backend: "file"` создаёт `.dat` файл. На exFAT (V:) быстро фрагментируется. На NTFS (W:) стабильнее для >4GB. Ventoy поддерживает путь к другому разделу через абсолютный `/ventoy/...` или явный `image:` + `persistence:`.
• `auto_install` требует точного совпадения имени ISO или regex. Поддерживает Windows (`autounattend.xml`), Ubuntu/Debian (`preseed.cfg`), RHEL (`ks.cfg`).
• Комментарии `#` игнорируются парсером → безопасно документировать конфиг прямо в JSON.
• Secure Boot (1.1.10+SB): `ventoy.json` не требует подписи, но кастомные `grub.cfg` или плагины должны быть в `EFI/BOOT/` с валидным хешем.

### 📐 Анализ в контексте цели
• Ваш диск `V:(exFAT)` → храните ISO и `ventoy.json`.
• Ваш диск `W:(NTFS)` → храните `.dat` файлы персистенса, `autounattend.xml`, драйверы, инструменты.
• JSON парсер Ventoy читает файл при каждой загрузке. Ошибка в синтаксисе → fallback в базовое меню. Валидация обязательна.
• Формат подачи: `Правила синтаксиса → Control (скорость) → Persistence/Auto (workflow) → Готовый шаблон → Валидация`.

### 📘 Гайд: ventoy.json (Написание | Чтение | Управление)

#### 1. Базовые правила (Чтение/Написание)
| Правило | Описание | Пример |
|---------|----------|--------|
| **Расположение** | Должен лежать в корне 1-го раздела (V:) или `/ventoy/ventoy.json` | `V:\ventoy.json` |
| **Синтаксис** | Строгий JSON. Запятые после последнего элемента запрещены. Кавычки только `""`. | ✅ `{"key": "val"}` ❌ `{key: val,}` |
| **Комментарии** | Поддерживаются только `#`. `//` и `/* */` сломают парсер. | `# Это комментарий` |
| **Пути** | Всегда `/`. Ventoy монтирует раздел виртуально. `\` работать не будет. | `/ISOs/ubuntu.iso` |

#### 2. Блок `control` (Управление скоростью/меню)
```json
{
  "control": {
    # Ускорить скан, ограничить глубину
    "VTOY_MAX_SEARCH_LEVEL": 2,
    # Игнорировать системный мусор
    "VTOY_FILT_DOT_UNDERSCORE_FILE": true,
    # Сортировать по алфавиту без учёта регистра
    "VTOY_SORT_CASE_SENSITIVE": false,
    "VTOY_SORT_LETTER_FIRST": true,
    # Таймаут автозагрузки (сек). 0 = ждать выбор.
    "VTOY_MENU_TIMEOUT": 10,
    # Показывать дерево папок вместо плоского списка
    "VTOY_TREE_VIEW_MODE": true,
    # Стартовая папка сканирования (оптимизация для V:)
    "VTOY_DEFAULT_SEARCH_ROOT": "/ISOs"
  }
}
```

#### 3. Блок `persistence` (Связывание ISO ↔ W:NTFS)
```json
{
  "persistence": [
    {
      # ISO на exFAT
      "image": "/ISOs/kali-linux-2024.1-amd64.iso",
      # .dat файл на NTFS (создаётся автоматически при 1-м запуске)
      "persistence": "/Data/kali_persistent.dat",
      "backend": "file" # file | disk
    },
    {
      "image": "/ISOs/ubuntu-24.04-desktop-amd64.iso",
      "persistence": "/Data/ubuntu_persistent.dat",
      "backend": "file"
    }
  ]
}
```
*Примечание:* Ventoy автоматически создаст `.dat` файл указанного размера при первом выборе пункта `Persistence` в меню. Размер задаётся параметром `size` (в MB) или выбирается в GUI.

#### 4. Блок `auto_install` (Безголовая установка)
```json
{
  "auto_install": [
    {
      "image": "/ISOs/Win11_23H2.iso",
      "template": "/Data/win11/autounattend.xml"
    },
    {
      "image": "/ISOs/ubuntu-24.04-desktop-amd64.iso",
      "template": "/Data/ubuntu/preseed.cfg"
    }
  ]
}
```

#### 5. Полный шаблон (Ready-to-Use)
Сохраните как `V:\ventoy.json`. Валидный JSON + комментарии + оптимизация под ваш split.
```json
{
  # === ГЛОБАЛЬНЫЙ КОНТРОЛЬ ===
  "control": {
    "VTOY_MAX_SEARCH_LEVEL": 2,
    "VTOY_FILT_DOT_UNDERSCORE_FILE": true,
    "VTOY_SORT_CASE_SENSITIVE": false,
    "VTOY_SORT_LETTER_FIRST": true,
    "VTOY_MENU_TIMEOUT": 15,
    "VTOY_TREE_VIEW_MODE": true,
    "VTOY_DEFAULT_SEARCH_ROOT": "/ISOs",
    # Исключить папки от скана
    "VTOY_EXCLUDE_PATH": ["/_Temp", "/_Logs"]
  },

  # === ПЕРСИСТЕНС (Связь ISO -> W:) ===
  "persistence": [
    {
      "image": "/ISOs/kali-linux-2024.1-amd64.iso",
      "persistence": "/Data/persistent/kali.dat",
      "backend": "file"
    }
  ],

  # === АВТОУСТАНОВКА ===
  "auto_install": [
    {
      "image": "/ISOs/Win11_23H2_x64.iso",
      "template": "/Data/win11/autounattend.xml"
    }
  ],

  # === ВИЗУАЛЬНЫЕ МЕТКИ ===
  "menu_class": [
    {"image": "/ISOs/*win*.iso", "class": "Windows"},
    {"image": "/ISOs/*ubuntu*.iso", "class": "Linux"},
    {"image": "/ISOs/*kali*.iso", "class": "Security"}
  ],

  # === ПСЕВДОНИМЫ (сокращают имена в меню) ===
  "menu_alias": [
    {"image": "/ISOs/kali-linux-2024.1-amd64.iso", "alias": "Kali 2024"}
  ]
}
```

#### 6. Управление и Валидация
| Действие | Команда/Действие | Примечание |
|----------|------------------|------------|
| **Проверка синтаксиса** | Вставьте в `jsonlint.com` или `jq . ventoy.json` (WSL2) | Ошибка `line X: column Y` → исправьте до перезагрузки |
| **Применение изменений** | Перезагрузите USB или выньте/вставьте. Ventoy читает JSON на лету. | Не требует `Ventoy2Disk.exe` переустановки |
| **Сброс к дефолту** | Переименуйте файл в `ventoy.json.bak` | Ventoy запустится с базовым сканом |
| **Лог отладки** | В меню нажмите `Ctrl+F` → появится debug-консоль | Показывает путь парсинга JSON и ошибки |

[RECOMMEND]
1. Для WSL2-валидации: `jq empty V:/ventoy.json && echo "OK" || echo "FAIL"`. Установите `jq` в WSL.
2. Создавайте `.dat` персистенса вручную (`fallocate -l 16G /mnt/w/Data/kali.dat`) для гарантии непрерывности блока на exFAT/NTFS.
3. Используйте `menu_class` + тему `grub2` для визуальной навигации, если >50 ISO.
