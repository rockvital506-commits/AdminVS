## 🔧 ПОШАГОВАЯ ИНСТРУКЦИЯ (ВЕРСИЯ 1.1.10)

### **ШАГ 1: Скачивание Ventoy 1.1.10**

```
1. Откройте браузер → https://www.ventoy.net/en/download.html
2. Скачайте последнюю версию для Windows (ventoy-1.1.10-windows.zip)
3. Распакуйте архив в папку C:\Ventoy\ (или другую удобную)
```

**⚠️ ПРЕДУПРЕЖДЕНИЕ:** Избегайте сторонних сборок (некоторые содержат рекламное ПО) [[4]].

**Альтернатива:** GitHub Releases → https://github.com/ventoy/Ventoy/releases

---

### **ШАГ 2: Определение буквы диска флешки**

```
1. Нажмите Win + X → выберите "Управление дисками" (diskmgmt.msc)
2. Найдите вашу флешку по объёму (~468 ГБ после форматирования)
3. Запомните букву диска (например, F:) и номер диска (например, Диск 1)
```

**Проверка через PowerShell:**
```powershell
Get-Disk | Select-Object Number, FriendlyName, Size, IsOffline | Format-Table
```

**⚠️ КРИТИЧЕСКИ ВАЖНО:** Убедитесь что выбрали именно флешку, а не системный диск!

---

### **ШАГ 3: Запуск Ventoy2Disk.exe**

```
1. Откройте папку C:\Ventoy\ventoy-1.1.10\
2. Найдите Ventoy2Disk.exe
3. ПКМ → Запуск от имени администратора
```

**Интерфейс Ventoy 1.1.10:**
```
┌─────────────────────────────────────────────────────────────┐
│  Ventoy2Disk 1.1.10                                         │
├─────────────────────────────────────────────────────────────┤
│  Device: [▼ USB Drive F: 468 GB       ]  [🔄 Refresh]       │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐    │
│  │  [Install]  [Upgrade]  [Clear]                       │    │
│  └─────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│  [Option]  [Config]  [Help]  [Exit]                         │
└─────────────────────────────────────────────────────────────┘
```

**Изменения в 1.1.10:**
- Кнопка **[Upgrade]** для обновления без потери ISO файлов [[4]]
- Меню **[Option]** содержит все настройки разделов [[1]]
- Кнопка **[Config]** для работы с ventoy.json [[17]]

### **ШАГ 4: Настройка параметров (МЕНЮ OPTION)**

```
1. Нажмите кнопку [Option] в нижнем левом углу
2. Откроется окно настроек с несколькими вкладками
```

---

#### **4.1 Вкладка "Partition Style" (Схема разделов)**

```
┌─────────────────────────────────────────────────────────────┐
│  Partition Style:                                           │
│  ○ MBR                                                      │
│  ● GPT          ← ВЫБРАТЬ ЭТО                               │
│                                                             │
│  [OK] [Cancel]                                              │
└─────────────────────────────────────────────────────────────┘
```

**Почему GPT:**
- Требуется для UEFI + Secure Boot на Windows 11 [[22]]
- Ventoy 1.0.14+ поддерживает Legacy загрузку с GPT [[26]]
- Лучшая защита таблицы разделов (дублирование)

---

#### **4.2 Вкладка "Secure Boot Support" (Безопасная загрузка)**

```
┌─────────────────────────────────────────────────────────────┐
│  Secure Boot Support:                                       │
│  ☑ Enable Secure Boot Support  ← ВКЛЮЧИТЬ (галочка)         │
│                                                             │
│  Note: Enabled by default since version 1.0.76 [[11]]       │
│                                                             │
│  [OK] [Cancel]                                              │
└─────────────────────────────────────────────────────────────┘
```

**Важно:**
- Включено по умолчанию с версии 1.0.76 [[11]]
- Требуется для загрузки на ПК с Windows 11 [[1]]
- При первой загрузке может потребоваться enrolment ключа [[22]]

---

#### **4.3 Вкладка "Partition Configuration" (Разделы)**

```
┌─────────────────────────────────────────────────────────────┐
│  Partition Configuration:                                   │
│                                                             │
│  File System: [▼ exFAT          ]  ← exFAT/NTFS/FAT32 [[1]] │
│                                                             │
│  ☑ Preserve some space at the end of the disk               │
│     Reserved Space: [172000] MB  ← 168 ГБ для Data раздела  │
│                                                             │
│  [OK] [Cancel]                                              │
└─────────────────────────────────────────────────────────────┘
```

**Ключевые настройки:**

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **File System** | **exFAT** | Поддержка файлов >4 ГБ, кроссплатформенность [[1]] |
| **Preserve space** | **ВКЛЮЧИТЬ** ✓ | Создаёт нераспределённое пространство для Data раздела [[23]] |
| **Reserved Space** | **172000 MB** | 168 ГБ × 1024 = 172032 МБ (округляем) [[24]] |

**Почему 172000 МБ:**
- 1 ГБ = 1024 МБ
- 168 ГБ × 1024 = 172032 МБ
- Ventoy 1.0.47+ снял лимит 2 ТБ на reserved space [[20]]

---

#### **4.4 Сохранение настроек**

```
1. Проверьте все вкладки:
   ☑ Partition Style: GPT
   ☑ Secure Boot Support: Enable
   ☑ File System: exFAT
   ☑ Reserved Space: 172000 MB

2. Нажмите [OK] для сохранения
3. Вернитесь в главное окно
```

```
1. В главном окне выберите вашу флешку в выпадающем списке
2. Нажмите [Install]
3. Подтвердите первое предупреждение:
```

### **ШАГ 6: Проверка установленной структуры**

```
1. Откройте "Управление дисками" (diskmgmt.msc)
2. Найдите вашу флешку
3. Проверьте структуру разделов
```

**Ожидаемая структура:**
```
┌─────────────────────────────────────────────────────────────┐
│  Диск X: USB Drive (~468 ГБ)                                │
├─────────────────────────────────────────────────────────────┤
│  Раздел 1: EFI System Partition — 32 МБ (FAT32, скрытый)    │
│  Раздел 2: Ventoy — ~300 ГБ (exFAT, буква диска)            │
│  Раздел 3: Unallocated — ~168 ГБ (для Data раздела)         │
└─────────────────────────────────────────────────────────────┘
```

**Проверка через PowerShell:**
```powershell
Get-Partition -DiskNumber X | Select-Object PartitionNumber, Type, Size, DriveLetter | Format-Table
```
**Замените X на номер вашей флешки.**

---

### **ШАГ 7: Создание второго раздела Data**

```
1. В "Управлении дисками" найдите нераспределённое пространство (~168 ГБ)
2. ПКМ на нераспределённой области → "Создать простой том"
3. Мастер создания тома:
   - Размер: Максимальный (все 168 ГБ)
   - Буква диска: Выберите свободную (например, G:)
   - Файловая система: NTFS
   - Метка тома: DATA_SECURE
   - Быстрое форматирование: ✓
4. Завершите мастер
```

**Почему NTFS для Data:**
- Поддержка BitLocker (требуется NTFS) [[24]]
- Журналирование для надёжности
- Сжатие файлов (опционально)

---

### **ШАГ 8: Включение BitLocker на разделе Data**

```
1. Откройте Проводник → найдите раздел DATA_SECURE (G:)
2. ПКМ на разделе → "Включить BitLocker"
3. Выберите способ разблокировки:
   ☑ Использовать пароль для блокировки диска
4. Введите надёжный пароль (минимум 12 символов)
5. Сохраните ключ восстановления:
   ☑ Сохранить в файл (на основной диск ПК)
   ☑ Распечатать ключ восстановления (рекомендуется)
6. Выберите режим шифрования:
   ☑ Использовать режим шифрования для съёмных дисков
7. Нажмите "Начать шифрование"
```

**Время шифрования:** ~30-60 минут для 168 ГБ (можно работать во время шифрования)

**Проверка через PowerShell:**
```powershell
Manage-bde -status G:
```

**Ожидаемый результат:**
```
Процент шифрования: 100.0%
Состояние защиты: Включено
Метод шифрования: XTS-AES 128
```

---

### **ШАГ 9: Проверка загрузки Ventoy (базовая)**

```
1. Безопасно извлеките флешку
2. Вставьте в тестовый ПК/ноутбук
3. Войдите в Boot Menu (F12/F11/Esc при загрузке)
4. Выберите флешку с пометкой UEFI
5. Должно появиться меню Ventoy
```

**Если появляется Secure Boot ошибка:**
```
1. При первой загрузке может появиться:
   "Verification failed: (15) Access denied"

2. Нажмите Enter → MOK Management → Enroll Key from Disk
3. Перейдите: EFI → ventoy → ENROLL_THIS_KEY.efi
4. Подтвердите → Reboot
5. Ventoy загрузится нормально [[22]]
```

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ (1.1.10)

| Проблема | Причина | Решение |
|----------|---------|---------|
| **Флешка не видна в Ventoy2Disk** | Нет прав администратора | Запустить от имени администратора [[4]] |
| **Secure Boot ошибка при загрузке** | Ключ не enrolled | MOK Management → Enroll Key from Disk [[22]] |
| **BitLocker не включается** | Файловая система не NTFS | Переформатировать Data раздел в NTFS |
| **Раздел Data не создаётся** | Reserved Space не настроен | Проверить Option → Partition Configuration [[23]] |
| **ISO не видны в меню** | Файл в глубокой папке | Переместить ISO ближе к корню или настроить ventoy.json [[4]] |
