
## 1. Сущности резервного копирования

### Полный образ (Full Image)
- **Суть/Смысл:** Абсолютная копия всех *используемых* блоков данных на разделе в конкретный момент времени. Это фундамент (точка отсчета) для любой цепочки резервного копирования. При развертывании не требует других файлов.
- **Оценка утилит:** 
  - *DiskGenius:* **Рейтинг: 7/10.** Создает поблочные или файловые образы разделов. Хорош для клонирования структуры, но не оптимизирован для горячего бэкапа живой Windows (VSS работает базово).
  - *Hasleo Backup Suite:* **Рейтинг: 9/10.** Использует VSS (Volume Shadow Copy) для создания снимка на блочном уровне без остановки системы. Идеально для системного раздела.

### Инкрементный образ (Incremental Image)
- **Суть/Смысл:** Копия *только тех блоков*, которые изменились с момента последнего бэкапа (полного или инкрементного). Экономит до 90% времени и места. Для восстановления системы требует наличия всей цепочки: Full + все последующие Incremental.
- **Оценка утилит:** 
  - *DiskGenius:* **Рейтинг: 2/10.** **Критическое ограничение:** В стандартной функциональности DiskGenius отсутствует механизм CBT (Changed Block Tracking) для инкрементальных бэкапов живой ОС. Он не умеет эффективно отслеживать изменения блоков на лету.
  - *Hasleo Backup Suite:* **Рейтинг: 9/10.** Нативно поддерживает CBT. Драйвер Hasleo отслеживает измененные сектора в фоновом режиме, что делает создание инкремента вопросом секунд.

### Сжатый образ (Compressed Image)
- **Суть/Смысл:** Образ, к которому применен алгоритм математического сжатия (например, LZ4 или LZMA). Данные упаковываются, чтобы занимать меньше физического места на носителе (P60/SD400). Плата за это — нагрузка на CPU (i7-12700H справится мгновенно) и невозможность прочитать файл образа без утилиты-создателя.
- **Оценка утилит:** 
  - *DiskGenius:* **Рейтинг: 5/10.** Поддерживает базовое сжатие при создании образов, но алгоритмы уступают специализированным бэкап-решениям.
  - *Hasleo Backup Suite:* **Рейтинг: 9/10.** Позволяет выбирать уровень сжатия (Normal/High). Высокое сжатие критически важно для SD400 (exFAT 512K), чтобы сэкономить место и снизить износ flash-ячеек.

### Ключевые концепции (First Principles)

**Блочный уровень (Block-level) vs Файловый уровень (File-level)**
- **Блочный уровень:** Утилита читает диск как массив секторов (блоков по 512 байт или 4КБ), игнорируя файловую систему (NTFS/exFAT). *Плюсы:* Скорость, захват удаленных файлов, точность. *Минусы:* Копирует "пустоту" (если не используется умное чтение).
- **Файловый уровень:** Утилита обращается к драйверу ФС, читает только существующие файлы и их метаданные. *Плюсы:* Пропускает пустое пространство. *Минусы:* Медленнее при полном бэкапе, не видит удаленные данные, сбоит при повреждении ФС.
*Для системных бэкапов всегда используется Блочный уровень через VSS.*

**CBT (Changed Block Tracking)**
- Это механизм (обычно драйвер ядра), который запоминает, какие именно блоки диска были перезаписаны с момента последнего снимка. Без CBT утилите для создания инкрементного образа пришлось бы прочитать *весь* диск и побайтово сравнить его с предыдущим образом. С CBT утилита просто запрашивает у драйвера список измененных блоков и копирует только их.

**Алгоритм выбора:**

1. **Если цель:** Создать надежный, сжатый бэкап живой системы Windows 11 с возможностью быстрого отката (Full + Incremental) → **Используй Hasleo Backup Suite Free**.
   * *Почему:* Только Hasleo имеет встроенный CBT и VSS-интеграцию, необходимые для инкрементальных бэкапов без простоя системы. DiskGenius для этой задачи архитектурно не приспособлен.

2. **Если цель:** Сделать "сырой" клон раздела, восстановить упавшую таблицу разделов, или снять образ с диска, который не загружается (мертвая ОС) → **Используй DiskGenius**.

   * *Носитель:* P60 или SD400 (в зависимости от размера образа).

**Золотое правило для вашей сборки:**
Используйте **Hasleo** для регулярного обслуживания и точек отката (Full раз в месяц, Incremental раз в неделю). Используйте **DiskGenius** как аварийный скальпель, когда Hasleo не может получить доступ к блокам из-за критического повреждения ФС.

## 1. Сущности резервного копирования

### Дифференциальный образ (Differential Image)

**Суть/Смысл:**
Дифференциальный образ копирует **все блоки данных, которые изменились с момента последнего полного (Full) бэкапа**. В отличие от инкрементного (который копирует изменения с момента *любого* предыдущего бэкапа), дифференциальный всегда ссылается на базовый Full-образ.

**Физические отличия от других типов:**

| Тип | Что копирует | Размер | Скорость создания | Скорость восстановления |
|-----|--------------|--------|-------------------|------------------------|
| **Full** | Все блоки | 100% | Медленно | Быстро (один файл) |
| **Incremental** | Изменения с последнего бэкапа | 1-5% | Очень быстро | Медленно (требует всю цепочку) |
| **Differential** | Изменения с последнего Full | 5-50% (растет) | Быстро | Быстро (Full + последний Diff) |
| **Compressed** | Сжатые данные любого типа | 30-70% от оригинала | Зависит от CPU | Требует распаковку |

**Когда применять:**
- Нужен баланс между скоростью создания и скоростью восстановления
- Не хотите хранить длинные цепочки инкрементов (риск потери одного файла = потеря всей цепочки)
- Регулярность бэкапов: раз в неделю/месяц (не каждый день)
- Критично быстрое восстановление без "сборки" из множества файлов

**Как работает на уровне диска:**
1. Hasleo/DiskGenius сравнивает битовую карту блоков текущего состояния диска с битовой картой на момент создания Full-образа
2. Выявляет все блоки, где бит изменился с 0 на 1 или наоборот
3. Копирует только эти измененные блоки в новый файл-образ
4. Файл дифференциального образа растет линейно: чем больше времени прошло после Full, тем больше изменений

---

**Оценка утилит:**

### DiskGenius (DGEng6201821_x64)
- **Рейтинг эффективности: 3/10**
- **Ключевые возможности:**
  - Поддерживает создание образов разделов (Partition Backup)
  - Может работать с образами в форматах .img, .pmf
  - Имеет базовое сжатие
- **Ограничения/Риски:**
  1. **Отсутствие нативной поддержки дифференциальных бэкапов** — DiskGenius не имеет встроенного механизма CBT (Changed Block Tracking) для отслеживания изменений между сессиями
  2. **Нет VSS-интеграции** — при бэкапе живой системы Windows может блокировать файлы, приводя к неконсистентным образам
  3. **Ручное управление цепочками** — пользователь сам должен отслеживать, какой Full-образ является базовым для дифференциального
  4. **Ограниченная автоматизация** — нет планировщика задач для регулярного создания дифференциальных образов
  5. **Проприетарный формат без документации** — образы .pmf сложно конвертировать в другие форматы
  6. **Риск повреждения цепочки** — при удалении или перемещении Full-образа все зависимые дифференциальные становятся невалидными без предупреждения

### Hasleo Backup Suite Free (v5.4.2.5)
- **Рейтинг эффективности: 9/10**
- **Ключевые возможности:**
  - Нативная поддержка Full/Incremental/Differential бэкапов
  - VSS (Volume Shadow Copy) для консистентных снимков живой системы
  - CBT-драйвер для быстрого отслеживания изменений
  - Автоматическое управление цепочками бэкапов
  - Шифрование AES-256 и сжатие
  - Universal Restore для разворачивания на другое железо
- **Ограничения/Риски:**
  1. **Проприетарный формат .hlb** — образы нельзя открыть сторонними утилитами без Hasleo
  2. **Зависимость от цепочки** — удаление Full-образа делает все дифференциальные невалидными (хотя Hasleo предупреждает об этом)
  3. **Рост размера дифференциального образа** — без периодического создания нового Full-образа дифференциальный может достичь размера полного
  4. **Требование одинакового пути** — при восстановлении дифференциального образа базовый Full должен быть доступен по тому же пути
  5. **Ограничение бесплатной версии** — нет поддержки Linux-разделов, только Windows (NTFS/FAT/exFAT)
  6. **Риск при прерывании процесса** — если создание дифференциального образа прервано (отключение питания), файл может быть поврежден без возможности восстановления

- DiskGenius архитектурно не поддерживает дифференциальные бэкапы (только полные образы)
- Hasleo имеет встроенный CBT-драйвер и VSS-интеграцию
- Скорость создания: 2-10 минут (против 30-60 минут для Full)
- Восстановление требует только 2 файла: Full + последний Differential (против полной цепочки Incremental)

### Оптимальная стратегия для вашей сборки:
```
Неделя 0: Full_2026-06-01.hlb (30-60 мин, ~50GB)
Неделя 1: Diff_2026-06-08.hlb (5 мин, ~2GB)
Неделя 2: Diff_2026-06-15.hlb (5 мин, ~3GB)
Неделя 3: Diff_2026-06-22.hlb (5 мин, ~4GB)
Неделя 4: Full_2026-06-29.hlb (30-60 мин, ~52GB) ← Новый базовый образ
```

**Правило ротации:** Создавайте новый Full-образ каждый месяц (или когда дифференциальный достигает 50% размера полного). Это предотвращает неограниченный рост дифференциальных файлов и ускоряет восстановление.

**Носитель:** P60 (NTFS 64K) — оптимально для скорости записи и долговечности цепочки. SD400 (exFAT 512K) подходит для хранения, но медленнее при создании.

**Критическое предупреждение:** Никогда не удаляйте Full-образ, если от него зависят дифференциальные бэкапы. Hasleo предупредит об этом, но если вы принудительно удалите файл через Проводник — вся цепочка станет невалидной без возможности восстановления.
